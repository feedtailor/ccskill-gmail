## 概要

`create_draft` および `create_reply_draft` で添付ファイルを付けた下書きを作成できるようにする。
Claude Code 標準 Gmail MCP にもない機能であり、ccskill-gmail 独自の差別化ポイントとなる。

## 背景

GmailApp の `createDraft` は `options.attachments` に `BlobSource[]` を渡すことで
添付ファイル付き下書きを作成できる。現在この機能は未実装。

業務メールでは添付ファイル付きの下書き作成は一般的なユースケースであり、
既存の `get_attachment`（添付DL）と対になる機能として価値が高い。

## 実装内容

### 1. 添付データの受け渡し方式の検討

POST リクエストで添付データを送る方式を決定する必要がある：

- **方式A**: base64 エンコードした内容を JSON に含める
  ```json
  {
    "action": "create_draft",
    "to": "...",
    "subject": "...",
    "body": "...",
    "attachments": [
      {
        "filename": "report.pdf",
        "contentType": "application/pdf",
        "content": "<base64>"
      }
    ]
  }
  ```
- GAS 側で `Utilities.newBlob(Utilities.base64Decode(content), contentType, filename)` でBlobに変換

### 2. gas-template/handlers/draft.js の修正

- `handleCreateDraft` に `attachments` パラメータ（任意、配列）を追加
- base64 → Blob 変換処理を実装
- `buildEmailOptions` に `attachments` を渡す

### 3. gas-template/handlers/draft.js の handleCreateReplyDraft を修正

- 同様に `attachments` パラメータを追加

### 4. gas-template/utils/gmail.js の buildEmailOptions を修正

- `attachments` の受け口を追加

### 5. サイズ制限の考慮

- GAS の POST リクエストボディサイズ制限を考慮
- 添付ファイル合計サイズの上限チェック（目安: 5MB）
- 上限超過時はエラーメッセージで通知

### 6. スキルドキュメント更新

- reference/draft.md に添付ファイルの使い方を追加
- SKILL.md の API 一覧を更新
- examples.md に使用例追加
