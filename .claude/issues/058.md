## 概要

README.md を、非エンジニアも含む一般の Claude Code ユーザー向けに再構成する。
API コマンドの詳細は SKILL.md（エージェントが読むドキュメント）に委譲し、
README は「何ができるか」「どう始めるか」「安全か」に集中させる。

## 背景

現状の README は開発者向けに寄っており、API 一覧やコマンド詳細が並んでいる。
実際のユーザーは「Claude Code に Gmail を使わせたい人」であり、
API を直接叩くのではなく自然言語で指示する使い方が主。

## 方針

### README に残すもの
- **何ができるか**: 自然言語での使用例を中心に
- **インストール方法**: 前提条件 → 手順をそのまま実行すれば動く形で
- **セキュリティ**: 何が守られているか（設計原則・認証・インジェクション対策）
- **更新・アンインストール方法**: 最低限のコマンド

### README から削除/移動するもの
- API 一覧表（GET/POST の詳細） → 「SKILL.md を参照」に置き換え
- コマンド詳細表 → 基本の install/update/uninstall のみ残す
- プロジェクト構成（ディレクトリツリー） → CLAUDE.md に既にある
- 制限事項の古い記載（添付ファイル未対応 → 実は対応済み）

### トーンの変更
- 技術用語は必要最低限に
- 「Claude Code に話しかけるだけ」という体験を前面に
