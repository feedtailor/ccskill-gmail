## タスク概要

メールの添付ファイルを取得し、ローカルにダウンロードする機能を実装する。

## 背景

現在のスキルではメール本文の閲覧は可能だが、添付ファイルの取得はできない。
業務利用において添付ファイルへのアクセスは重要なユースケース。

## GAS 側実装

### 新規エンドポイント

**`get_attachment`** (GET)

- パラメータ:
  - `message_id` (必須): メッセージ ID
  - `attachment_index` (必須): 添付ファイルのインデックス（0始まり）
- レスポンス:
  ```json
  {
    "ok": true,
    "data": {
      "filename": "report.pdf",
      "contentType": "application/pdf",
      "size": 123456,
      "content": "<base64 encoded>"
    }
  }
  ```

**`list_attachments`** (GET)

- パラメータ:
  - `message_id` (必須): メッセージ ID
- レスポンス:
  ```json
  {
    "ok": true,
    "data": {
      "messageId": "...",
      "attachments": [
        {
          "index": 0,
          "filename": "report.pdf",
          "contentType": "application/pdf",
          "size": 123456
        }
      ]
    }
  }
  ```

### 実装箇所

- `gas-template/handlers/read.js` に `list_attachments` ハンドラ追加
- `gas-template/handlers/read.js` に `get_attachment` ハンドラ追加
- `gas-template/main.js` のルーティングに追加

## サイズ制限への対応

- GAS のレスポンスサイズ制限と実行時間制限を考慮
- 大きなファイル（目安: 5MB 超）の場合はエラーメッセージで通知
- `list_attachments` で事前にサイズ確認できる設計

## Claude Code 側の利用パターン

```bash
# 添付ファイル一覧を確認
ccskill-get "$GMAIL_ENDPOINT" action=list_attachments message_id=MSG_ID

# 添付ファイルをダウンロード（base64 デコードして保存）
ccskill-get "$GMAIL_ENDPOINT" action=get_attachment message_id=MSG_ID attachment_index=0 \
  | jq -r '.data.content' | base64 -d > report.pdf
```
