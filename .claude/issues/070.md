## 概要

SSH 経由やヘッドレス環境での install 時に、ブラウザが開けず認証フローが詰まる問題を解決する。

## 背景

別マシンに SSH で接続して `ccskill-gmail install` を実行した際、以下の問題が発生した:

1. `open` コマンドでブラウザが開けない（SSH 先にはデスクトップがない）
2. OAuth 認証 URL が表示されないため、ユーザーが手動でブラウザに貼る URL がわからない
3. Enter を押すタイミングが不明確
4. Apps Script API 未有効化時のエラーメッセージが不正確

## 改善内容

### 1. OAuth URL の併記

「Press Enter to open the authorization page...」の箇所で、Web App の exec URL を常に表示する:

```
If the browser doesn't open automatically (e.g. SSH environment),
open this URL manually:
  https://script.google.com/macros/s/DEPLOY_ID/exec
```

### 2. Enter タイミングの案内

```
Press Enter after completing the authorization...
```

を以下のように改善:

```
After the browser shows {"ok":true,...}, press Enter to continue...
```

### 3. Apps Script API 未有効化のエラーメッセージ改善

現在:
```
This usually means your Google credentials have expired.
Run the following to re-authenticate:
  ccskill-gmail setup
```

改善後:
```
The Apps Script API is not enabled for this account.
Enable it at: https://script.google.com/home/usersettings
Then re-run: ccskill-gmail install
```

## 完了条件

- [ ] OAuth 認証画面で exec URL が表示される

- [ ] Apps Script API 未有効化時に正しいエラーメッセージと URL が表示される
- [ ] SSH 経由での install が URL 手動コピーで完了できる
