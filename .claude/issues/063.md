## 概要

ccskill シリーズを一元配布するための Claude Code プラグインマーケットプレイスを
`feedtailor/ccskill` リポジトリとして構築する。

## 背景

ccskill シリーズは feedtailor ブランドで複数のプラグインを公開予定:

| プラグイン | 状態 |
|-----------|------|
| ccskill-nanobanana | 公開済み（プラグイン未対応） |
| ccskill-gmail | 公開準備中（#062） |
| ccskill-spreadsheet | 開発中 |
| ccskill-webapp | 開発中 |

ユーザーの導線:
```bash
/plugin marketplace add feedtailor/ccskill
/plugin install ccskill-gmail@ccskill
```

命名規則:
- マーケットプレイス名: `ccskill`
- プラグイン名: `ccskill-gmail`, `ccskill-spreadsheet` 等（リポジトリ名と一致）
