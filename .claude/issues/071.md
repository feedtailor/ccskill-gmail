## 概要

setup および install の完了メッセージを改善し、次のアクションを明確にする。

## 背景

- setup 後に `ccskill-gmail` コマンドが tab 補完されず、ユーザーが「使えない？」と混乱する
- install 後に疎通確認の方法が案内されない
- smoke test の存在が知られていない

## 改善内容

### 1. setup 完了メッセージに tab 補完リセット案内

```
Note: Tab completion may not work until you run 'hash -r'
or open a new terminal.
```

zsh はコマンドキャッシュ（ハッシュテーブル）を持っており、PATH に新しいコマンドが追加されても即座に tab 補完に反映されないため。

### 2. install 完了メッセージに疎通確認コマンドの案内

```
Verify the installation:
  .ccskill-gmail/api get action=get_profile
```

install スクリプト内で health check は行っているが、ユーザー自身が API を叩いて確認できると安心感がある。

### 3. smoke test の存在案内

```
To run a full API test (for developers):
  ~/projects/ccskill-gmail/tests/smoke-test.sh .
```

開発者向けの注記を添えて、全 API の動作確認方法を案内する。
