Skill 02

ccskill-gmail

Safe AI email automation. Search, read, draft, export — Claude handles the busy work while you stay in control. No send API by design. 安全なAIメール自動化。検索、閲覧、下書き、エクスポート——送信APIなしの安心設計で、面倒な作業をClaudeに任せよう。

Search & Read Draft Attachments PDF Export Audit Log No Send API Injection Protection
"Show me unread emails from today" 「今日の未読メールを見せて」
"Find all receipt emails from ACME Corp in the last 6 months and save attached PDFs with standardized filenames" 「○○社からの領収書メールを直近半年分探して、添付PDFを命名規則に沿って保存して」
"Trace all emails with John at ACME and create a handover document with open tasks. Export as Excel" 「○○社の○○さんとのやり取りを全て遡り、引き継ぎ資料を作成して。一覧はExcelで」
"Find external emails I haven't replied to in the past month. List by sender, subject, and days pending. Draft follow-ups for important ones" 「過去1ヶ月で返信していない取引先メールを洗い出して、相手先・件名・放置日数の一覧を作って。重要なものにはフォローアップの下書きも作って」
"Review all external emails this week, categorize as needs-reply / FYI / resolved, compile a weekly report" 「今週届いた社外メールを全件レビューして、要返信・FYI・対応完了に分類し、週次レポートにまとめて」
