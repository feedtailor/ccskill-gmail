## 概要

複数の threadId に対してまとめて操作を実行できる一括操作 API を追加する。
安全性のため dryRun モードを必須とする設計。

## 対象アクション

- bulk_mark_read / bulk_mark_unread
- bulk_add_label / bulk_remove_label
- bulk_archive

## 設計方針

- dryRun: true の場合は対象一覧を返すのみ（実行しない）
- 上限: 1回あたり最大 50 件
- レスポンスに成功/失敗の内訳を含める
