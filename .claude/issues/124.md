## 概要

スキルを `~/.claude/skills/ccskill-gmail` に登録できるようにし、ドキュメントをグローバル表記 (`ccskill-gmail api`) に全面改訂する。この Phase の完了で要求 (A)(B) がプロンプトから使える状態になる — リリースの主役。全体方針は #121 を参照。

## 実装内容

1. **`commands/skill.sh` (新規)** — `ccskill-gmail skill install`: `~/.claude/skills/ccskill-gmail` → マスター `.claude/skills/ccskill-gmail/` への symlink 作成。symlink 不可環境用 `--copy` (この場合のみ update で再コピー)。`skill uninstall` も対で用意。`~/.claude/settings.json` には触れない (permission は案内表示のみ、#121 の不可侵方針)
2. **ドキュメント表記統一 (約 170 箇所、機械的)** — SKILL.md (23) / SKILL.ja.md (同等) / examples.md (65) / reference/* (67) / troubleshooting.md の `.ccskill-gmail/api` → `ccskill-gmail api`。`.ccskill-gmail/tmp/` 表記は維持 (cwd 相対のまま、api が実行時に mkdir)
3. **SKILL.md にアカウント行動規範を追加** (#121 の誤アカウント対策):
   - 結果報告で必ず対象アカウントを明示する
   - ユーザーがメールアドレス/ラベルを指名した時のみ `--account` を付与する
   - 曖昧 (複数登録 + バインドなし + 不明瞭な指名) なら実行前にユーザーへ確認する
   - post は直前の get と同じ `--account` を引き継ぐ (会話途中の暗黙切替禁止)
4. **frontmatter 更新** — description をグローバル前提に書き直し (「cd したプロジェクトに紐づく」記述の更新)。`allowed-tools` の permission パターンは #122 の検証結果に従う
5. **lib/permissions.sh 拡張** — `Bash(ccskill-gmail api:*)` 系パターンを追加 (レガシーパターンは残置)
