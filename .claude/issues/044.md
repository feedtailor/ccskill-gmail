## 概要

`create_draft` および `create_reply_draft` で HTML 形式の本文を指定できるようにする。
Claude Code 標準 Gmail MCP では `contentType: "text/html"` で対応済みの機能。

## 背景

`buildEmailOptions` (gas-template/utils/gmail.js) には既に `htmlBody` の受け口があるが、
`handleCreateDraft` / `handleCreateReplyDraft` のパラメータとして公開されていない。
MCP との機能差を埋めるとともに、リッチなメール下書き作成を可能にする。

## 実装内容

### 1. gas-template/handlers/draft.js の handleCreateDraft を修正

- `htmlBody` パラメータ（任意）を追加
- `buildEmailOptions` に `htmlBody` を渡す
- `body`（プレーンテキスト）は引き続き必須（フォールバック用）

### 2. gas-template/handlers/draft.js の handleCreateReplyDraft を修正

- 同様に `htmlBody` パラメータ（任意）を追加

### 3. gas-template/main.js のルーティングで htmlBody パラメータを渡す

### 4. スキルドキュメント更新

- reference/draft.md に htmlBody パラメータの説明追加
- SKILL.md の API 一覧を更新
