## タスク概要

メッセージまたはスレッドにラベルを追加/削除する `add_label` / `remove_label` API を実装する。

## API 仕様

### add_label

**アクション**: `add_label`
**メソッド**: POST

| パラメータ | 必須 | 説明 |
|-----------|------|------|
| threadId | ※ | スレッド ID（threadId または messageId のいずれか必須） |
| messageId | ※ | メッセージ ID |
| label | ✓ | ラベル名 |

### remove_label

**アクション**: `remove_label`
**メソッド**: POST

| パラメータ | 必須 | 説明 |
|-----------|------|------|
| threadId | ※ | スレッド ID |
| messageId | ※ | メッセージ ID |
| label | ✓ | ラベル名 |

### レスポンス例

```json
{
  "ok": true,
  "data": {
    "threadId": "19bf7f25b96ab637",
    "label": "対応済",
    "action": "add_label",
    "message": "ラベル「対応済」を追加しました"
  }
}
```

## 実装内容

### 1. handlers/label.js を新規作成

```javascript
/**
 * Gmail Skill - Label Handlers
 *
 * Label operations: add, remove.
 */

function handleAddLabel(threadId, messageId, labelName) {
  requireParam(labelName, 'label');

  if (!threadId && !messageId) {
    return errorResponse('Either threadId or messageId is required');
  }

  // ラベルを取得または作成
  let label = GmailApp.getUserLabelByName(labelName);
  if (!label) {
    label = GmailApp.createLabel(labelName);
  }

  if (threadId) {
    const thread = GmailApp.getThreadById(threadId);
    if (!thread) {
      return errorResponse(`Thread not found: ${threadId}`);
    }
    thread.addLabel(label);
    return successResponse({
      threadId: threadId,
      label: labelName,
      action: 'add_label',
      message: `ラベル「${labelName}」を追加しました`
    });
  } else {
    // Note: GmailApp doesn't support adding labels to individual messages
    // Need to use Gmail Advanced Service for this
    return errorResponse('Adding label to individual message is not supported. Use threadId instead.');
  }
}

function handleRemoveLabel(threadId, messageId, labelName) {
  requireParam(labelName, 'label');

  if (!threadId && !messageId) {
    return errorResponse('Either threadId or messageId is required');
  }

  const label = GmailApp.getUserLabelByName(labelName);
  if (!label) {
    return errorResponse(`Label not found: ${labelName}`);
  }

  if (threadId) {
    const thread = GmailApp.getThreadById(threadId);
    if (!thread) {
      return errorResponse(`Thread not found: ${threadId}`);
    }
    thread.removeLabel(label);
    return successResponse({
      threadId: threadId,
      label: labelName,
      action: 'remove_label',
      message: `ラベル「${labelName}」を削除しました`
    });
  } else {
    return errorResponse('Removing label from individual message is not supported. Use threadId instead.');
  }
}
```

### 2. main.js の doPost に追加

```javascript
case 'add_label':
  return handleAddLabel(body.threadId, body.messageId, body.label);

case 'remove_label':
  return handleRemoveLabel(body.threadId, body.messageId, body.label);
```

## 注意事項

- GmailApp はスレッド単位でのラベル操作のみサポート
- 個別メッセージへのラベル操作は Gmail Advanced Service (Gmail API) が必要
- 存在しないラベルを add_label で指定した場合は自動作成

## テスト方法

```bash
# ラベルを追加
curl -sL --max-time 60 \
  -H "Content-Type: application/json" \
  --data '{"action":"add_label","threadId":"THREAD_ID","label":"対応済"}' \
  "$GMAIL_ENDPOINT"

# ラベルを削除
curl -sL --max-time 60 \
  -H "Content-Type: application/json" \
  --data '{"action":"remove_label","threadId":"THREAD_ID","label":"対応済"}' \
  "$GMAIL_ENDPOINT"

# ラベル一覧で確認
curl -sL --max-time 60 "$GMAIL_ENDPOINT?action=list_labels" | jq '.data.labels[] | select(.name == "対応済")'
```
