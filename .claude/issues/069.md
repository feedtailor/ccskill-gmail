## 概要

PR #1（setup コマンド）の新規ユーザーテストで判明した README の改善点を対応する。

## 背景

別マシンでの完全新規インストールテスト時に、初めてのユーザーが躓くポイントが複数見つかった。

## 改善内容

### 1. 前提条件（Requirements）に追記

- **Apps Script API の有効化**: 初めて GAS を使うアカウントでは https://script.google.com/home/usersettings で API を有効にする必要がある。install 前の前提条件として明記する

### 2. clasp スコープの説明

Google 認証時に求められる8つの権限（Drive ファイル参照、Apps Script プロジェクト管理等）が何のために必要かを表で説明する。初めてのユーザーが安心して許可できるようにする目的。

### 3. トラブルシュートセクションの新設

以下の内容を記載:

- **install が途中で失敗した場合**: 再度 `ccskill-gmail install` を実行すると「Overwrite?」と聞かれるので `y` で上書きすればよい
- **複数 Google / Workspace アカウント使用時**: OAuth 認証で「ファイルを開けません」エラーが出る場合、シークレットウィンドウで認証 URL を開くことを推奨
- **「ファイルを開くことができません」エラー**: ブラウザでログイン中のアカウントと GAS プロジェクトを作成したアカウントが異なる場合に発生。シークレットウィンドウまたはアカウント切り替えで解決

### 4. Plugin セクションの削除

「As a Claude Code Plugin」セクションは未実装のため削除する。

### 5. README.ja.md の更新

setup コマンドによるセットアップ簡素化が README.ja.md に反映されていない。README.md と同期させる。
