## 概要

SKILL.md とそこから参照されるスキル定義ドキュメント群を英語をマスターとして整備する。

## 背景

ccskill-gmail をインストールした後、Claude Code で skill 一覧を表示すると description が日本語で表示される。国際ユーザーにとって障壁となる。

SKILL.md は Claude Code が読む指示書であり、Claude は英語でも日本語でも理解するが、description 等のメタ情報は英語が望ましい。

## 方針

**英語マスター方式（案A）を採用:**
- SKILL.md を英語に書き換える（Claude が読むものなので日本語版は不要）
- examples.md / troubleshooting.md も英語化
- reference/ 配下のファイルも英語化
- 日本語版（`*.ja.md`）は作成しない（Claude 向けドキュメントのため）

## 対象ファイル

- `.claude/skills/ccskill-gmail/SKILL.md`
- `.claude/skills/ccskill-gmail/examples.md`
- `.claude/skills/ccskill-gmail/troubleshooting.md`
- `.claude/skills/ccskill-gmail/reference/` 配下
