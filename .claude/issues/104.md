## 概要

レシピを自然言語呼び出しとスラッシュコマンド (`/gmail-<recipe>`) の両方から発動できるようにする (A+C ハイブリッド方式)。あわせて `ccskill-gmail recipe` サブコマンドを CLI に追加する。

## 背景

#102 の構想に基づく Phase 2。#103 でレシピの器はできるが、現状は手動で prompt.md をコピペする必要がある。発動機構を整備することで初めて「レシピを実用的に使える」状態になる。

発動方式として議論された A-D の中から、以下の理由で A+C を採用:

- A (自然言語): ユーザー体験が自然、経営者層が打ちやすい
- C (`/gmail-<recipe>` 独立スラッシュ): 素早く叩ける、タブ補完が効く
- A+C ハイブリッド: デフォルトは自然言語、高頻度レシピは install でスラッシュコマンド化

## 実装内容

### 1. 自然言語呼び出し (方式 A)

SKILL.md に行動ルールを追加:
- 「`<レシピ名>` のレシピをやって」「`<レシピ名>` して」等の依頼を検出
- `recipes/` 配下を走査し、合致するレシピを特定
- `recipes/<name>/prompt.md` を読んで実行
- あいまい呼び出しの場合は候補を提示して確認

### 2. スラッシュコマンド自動登録 (方式 C)

- `ccskill-gmail recipe install <name>` 時に `.claude/commands/gmail-<name>.md` を配置
- コマンド内容は `recipes/<name>/prompt.md` の内容を include する最小 wrapper
- uninstall 時に対応する commands ファイルも削除
- 命名規約: **`gmail-` プレフィクス強制**。他 ccskill 系スキル (spreadsheet 等) との衝突を避ける
- 既存の `.claude/commands/` との衝突を install 時にチェックしエラー

### 3. CLI 拡張

| コマンド | 動作 |
|---|---|
| `ccskill-gmail recipe list` | 利用可能/インストール済みレシピの一覧 |
| `ccskill-gmail recipe show <name>` | レシピの README + prompt を表示 |
| `ccskill-gmail recipe install <name>` | スラッシュコマンドを登録 |
| `ccskill-gmail recipe uninstall <name>` | スラッシュコマンドを削除 |

### 4. doctor / status / info への反映

- `doctor`: 登録済みレシピ・登録エラー (衝突等) の確認
- `info` / `status`: 登録済みレシピ数の表示
