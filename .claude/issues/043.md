## 概要

認証済みユーザーのプロフィール情報を取得する `get_profile` アクション（GET）を追加する。
Claude Code 標準 Gmail MCP に存在する機能であり、これを実装することで MCP との機能差を埋める。

## 背景

MCP の `gmail_get_profile` はメールアドレスやメールボックス統計情報を返す。
ccskill-gmail にはこれに相当する機能がなく、現在のアカウント情報を確認する手段がない。

## 実装内容

### 1. gas-template/handlers/read.js に handleGetProfile を追加

- `Session.getActiveUser().getEmail()` でメールアドレス取得
- `GmailApp.getInboxUnreadCount()` で未読数取得
- スレッド総数等の追加情報も可能な範囲で返す

### 2. gas-template/main.js のルーティングに get_profile を追加

- GET リクエストで `action=get_profile` を受け付ける

### 3. スキルドキュメント更新

- .claude/skills/ccskill-gmail/reference/ に適切なドキュメント追加
- SKILL.md の API 一覧に追加
