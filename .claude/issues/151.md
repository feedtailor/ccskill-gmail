## 概要

`account add` が作る GAS プロジェクト名は現在 `Gmail Skill - account <label|clasp_user>` で長い。
これを短くし、**作成マシンの短縮ホスト名**を `[hostname]` として付与する。Apps Script の
一覧で「どのマシンが作ったか」を一目で分かるようにする。


## 出典

#147-149 の GAS 乱立の後、ユーザーから「マシン名（Tailscale 名 om4mba/om1ms）を名前に入れたい」
「`Gmail Skill - account …` は長い、`ccskill-gmail [om1ms]` のように短くしたい」との要望。
`hostname -s` が `om4mba` を返すこと（Tailscale 名と一致）を om4mba 上で確認済み。


## 詳細

- 現状: `commands/account.sh:140`
  `provision_gas "$GAS_DIR" "Gmail Skill - account ${LABEL:-$_CLASP_USER}"`
- マシン名は `hostname -s` で取得（`om4mba`）。空/異常時は `hostname` の先頭ラベルにフォールバック。
- 反映は**新規作成分のみ**（clasp v3 に手軽なリネームがなく、既存名は手動リネーム）。

### 命名フォーマット（実装時に最終決定）

同一 Google アカウントの重複 add は #150 で弾く前提なので、名前でアカウントを区別する必要は薄い。
ユーザー希望を踏まえ短縮する。候補:

- `ccskill-gmail [om1ms]`（純粋・最短）
- `ccskill-gmail <label> [om1ms]`（ラベルがあれば付与）


## 方針

`hostname -s` で短縮ホスト名を得て、`ccskill-gmail … [<host>]` 形式の短いタイトルにする。
ホスト名取得は lib の小関数に切り出し、フォールバックを含めて単体テスト可能にする。


## スコープ外

- 既存 GAS プロジェクトの一括リネーム（手動対応）。
- Tailscale API 経由での tailnet 名取得（短縮ホスト名で足りるため）。

## 既知の制限

- 対話でラベルを付ける場合（2個目以降・`--label` 未指定）、ラベルは endpoint 検証後に決まるため
  **GAS タイトルには入らない**（`ccskill-gmail [host]` になる）。`--label` を明示した場合のみ
  タイトルにラベルが入る。タイトルは人間向けの補助表示であり、実害はないためこの挙動で許容する。
