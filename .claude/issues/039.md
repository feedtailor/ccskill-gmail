## タスク概要

メール本文の完全な HTML を取得するエンドポイントを追加する。
PDF 化はローカル側のツール（wkhtmltopdf, Chrome headless 等）で行う設計とし、
スキル定義にその手順とツールがない場合の案内を記載する。

## 背景

メールの印刷・PDF 保存は業務でよくあるユースケース。
GAS 内で PDF 化すると Drive スコープの追加が必要になるため、
HTML を返してローカルで PDF 変換する方式を採用する。
これにより現在のスコープ（gmail.readonly, gmail.compose, gmail.modify）を維持できる。

## GAS 側実装

### 新規エンドポイント

**`get_message_html`** (GET)

- パラメータ:
  - `message_id` (必須): メッセージ ID
  - `include_headers` (任意, デフォルト: true): From/To/Date/Subject ヘッダーを HTML 先頭に含めるか
- レスポンス:
  ```json
  {
    "ok": true,
    "data": {
      "messageId": "...",
      "subject": "Meeting Notes",
      "from": "alice@example.com",
      "to": "bob@example.com",
      "date": "2026-02-24T10:00:00.000Z",
      "html": "<!DOCTYPE html><html>..."
    }
  }
  ```

### 実装箇所

- `gas-template/handlers/read.js` に `get_message_html` ハンドラ追加
- `gas-template/main.js` のルーティングに追加

### GmailApp API

```javascript
const message = GmailApp.getMessageById(messageId);
const html = message.getBody(); // HTML 形式の本文

// include_headers=true の場合、ヘッダー情報を HTML に埋め込む
const headers = `
<div style="font-family: sans-serif; margin-bottom: 20px; padding: 10px; border-bottom: 1px solid #ccc;">
  <p><strong>From:</strong> ${message.getFrom()}</p>
  <p><strong>To:</strong> ${message.getTo()}</p>
  <p><strong>Date:</strong> ${message.getDate()}</p>
  <p><strong>Subject:</strong> ${message.getSubject()}</p>
</div>`;
```

```markdown
## メールの PDF 化

HTML 本文を取得してローカルツールで PDF に変換します。

### 手順
1. `get_message_html` で HTML を取得しファイルに保存
2. ローカルの PDF 変換ツールで変換

### 変換コマンド例
\```bash
# wkhtmltopdf の場合
wkhtmltopdf /tmp/email.html /tmp/email.pdf

# Chrome headless の場合
google-chrome --headless --print-to-pdf=/tmp/email.pdf /tmp/email.html
\```

### ツールがない場合
PDF 変換ツールがインストールされていない場合は、
HTML ファイルをブラウザで開いて「印刷 > PDF として保存」を案内してください。

\```
PDF 変換ツールが見つかりませんでした。
HTML ファイルを保存しました: /tmp/email.html

PDF として保存するには:
1. ブラウザで上記ファイルを開く
2. Cmd+P（印刷）> 「PDF として保存」を選択
\```
```
