## 概要

デプロイ済みの GAS Web App に対して全 API を叩いて ok/fail を判定するスモークテストスクリプトを作成する。

## 背景

- CLAUDE.md で TDD 徹底を謳っているが、自動テストの仕組みが存在しない
- GAS はローカル実行不可のため、デプロイ済み実機への API コールが唯一のテスト手段
- 既存のテスト手順は issue #006, #012, #018 に手動チェックリストとして散在しており再利用しにくい
- #067 のルーティングリファクタのように全アクションに影響する変更時、手動テストは非現実的

## 設計

### 配置

`tests/smoke-test.sh` — 開発者専用ツールとして `tests/` に配置する。

`ccskill-gmail` のサブコマンド体系（install/update/status 等）はスキル管理者・利用者向けであり、テストスクリプトはスキル開発者のみが使う開発用途ツール。この層の違いを明確にするためサブコマンドにはしない。

### 実行方法

```bash
./tests/smoke-test.sh ~/projects/ftgmail
```

### テスト対象

**GET アクション（10種）** — 読み取りのみなので安全に実行可能:

| # | アクション | テスト内容 |
|---|-----------|-----------|
| 1 | search | query=test で検索 |
| 2 | get_thread | search 結果から threadId を取得して実行 |
| 3 | get_message | search 結果から messageId を取得して実行 |
| 4 | list_labels | パラメータなし |
| 5 | get_unread_count | パラメータなし |
| 6 | list_attachments | メッセージ ID を指定 |
| 7 | get_attachment | 添付ありメッセージがあれば実行、なければスキップ |
| 8 | get_message_html | メッセージ ID を指定 |
| 9 | list_drafts | パラメータなし |
| 10 | get_profile | パラメータなし |

**POST アクション** — 副作用を必ず打ち消す:

| # | アクション | 打ち消し |
|---|-----------|---------|
| 11 | create_draft | → delete_draft で削除 |
| 12 | mark_read | → mark_unread で元に戻す |
| 13 | add_label | → remove_label で元に戻す |

**エラー系:**

| # | テスト | 期待する error_code |
|---|--------|-------------------|
| 14 | GET で POST アクション | WRONG_METHOD |
| 15 | POST で GET アクション | WRONG_METHOD |
| 16 | 存在しないアクション | UNKNOWN_ACTION |
| 17 | 必須パラメータなし | MISSING_PARAM |

### オプション

| フラグ | 動作 |
|--------|------|
| `--read-only` | GET + エラー系のみテスト（POST スキップ） |
| `--include-destructive` | archive / move_to_trash / bulk 系も実行（デフォルトスキップ） |

### 実装方針

- 引数でテスト対象ディレクトリを指定（特定プロジェクト非依存）
- 対象ディレクトリの `.ccskill-gmail/api` コマンドを使用
- レスポンスの `"ok":true` / `"ok":false` + `error_code` で判定
- jq 依存（レスポンス JSON のパース用）
