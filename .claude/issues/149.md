## 概要

#147 では jq のオブジェクトキー `label:` を quote したが、**真因は取りこぼしていた**。
jq 1.5 で `label` は予約語のため、キーだけでなく **変数名 `$label`（`--arg label`）**と
**ドット形式のフィールドアクセス `.label`** も解釈できず、アカウント登録が依然として失敗する。
識別子としての `label` を全て排除して根治する。


## 出典

#147 の fix を pull 済みの利用者マシン（jq-1.5）で `ccskill-gmail account add` を再実行した際の
エラー。quote 済みの行を指したまま同じ構文エラーが出ている。

```
jq: error: syntax error, unexpected label, expecting IDENT or __loc__ (Unix shell quoting issues?) at <top-level>, line 2:
          "label": (if $label == "" then null else $label end),
jq: 1 compile error
```

`expecting IDENT or __loc__` は jq の `$<name>` 文法規則のメッセージ。`$label`（予約語名の変数）が
真の失敗点であることを示す。


## 詳細

### #147 の何が不足していたか（実 jq 1.5 で切り分け）

jq 1.5 バイナリを入手して各構文を実測した結果、**予約語が壊すのは「変数名」だけ**だった。

| 構文 | jq 1.5 実測 | 判定 |
|---|---|---|
| bare キー `{label: 1}` | ✅ 動く | #147 の quote は不要（無害なので維持） |
| フィールドアクセス `.value.label` / `.label` | ✅ 動く | 変更不要 |
| `--arg label` → `$label` | ❌ `unexpected label` | **実害（登録失敗の真因）** |
| `.x as $def` → `$def` | ❌ `unexpected def` | **実害（account list の失敗）** |

`$label` はアカウント**登録**（`accounts_upsert`）で失敗。`$def` は `account list` の
表示で失敗。`accounts_get` / `accounts_label_exists` は予約語変数を使っておらず（`$i` / `$l`）、
フィールドアクセスは 1.5 でも動くため、**api 実行時の名前解決は元から 1.5 で問題なかった**。

### 該当箇所（変数名のみ修正）

- `lib/accounts.sh`: `--arg label`(144) → `--arg lbl` / `$label`(153) → `$lbl`
- `commands/account.sh`: `.default_account as $def`(223) → `as $defacct`（225 の参照も）


## 方針

jq 1.5 で実害のある「予約語の変数名」だけを非予約語に改名する（最小差分）。

- 変数: `--arg label` → `--arg lbl`（`$lbl`）、`as $def` → `as $defacct`
- フィールドアクセス・オブジェクトキーは 1.5 でも動くため変更しない
  （#147 の `"label":` quote は無害なので維持）
