## 概要

#136 で確定した方針を実装する。`install`(central) を deprecated 化して `bind` へ委譲し、`install --dedicated` / `--user`（専用GAS新規作成）を退役させる。既存インストール（専用GAS含む）は動作不変で、畳むのは「新規に作る手段」のみ。

## 実装内容

### 1. `commands/install.sh`

- **central パス**（`_DEDICATED != true`）: 退役警告を表示し、アカウント解決後 `bind` へ委譲する。
  - アカウント解決（`--account` 指定 > デフォルト）は維持。未登録なら従来どおり `account add` を案内して非ゼロ終了。
  - 解決できたら `commands/bind.sh bind <email> <TARGET_DIR> [--yes]` を実行（binding.json + setup_permissions）。
  - スキル定義コピー・プロジェクト api 配置・registry 登録・`.gitignore` 設定は**行わない**。
- **dedicated パス**（`--dedicated` / `--user`）: 退役エラーを表示して非ゼロ終了。`skill install` + `bind`（既存専用GASはそのまま動作）へ誘導する。GAS 新規作成処理（provision 等）には進まない。

### 2. ディスパッチャ `ccskill-gmail`

- ヘルプの `install` 行に deprecated 注記を付す（`bind` を案内）。

### 3. `commands/doctor.sh`

- `Fix: ccskill-gmail install` 系の案内を global 導線（`ccskill-gmail account add` / `ccskill-gmail bind` / `ccskill-gmail skill install`）へ差し替える。

### 4. ドキュメント

- `docs/commands.md` / `docs/commands.ja.md`: `install [--dedicated]` 行を deprecated・退役前提の記述へ。
- `docs/security-decisions.md` / `docs/security-decisions.ja.md`: 「Dedicated per-project deployments remain available via `install --dedicated`」を退役後の記述（既存専用GASはレガシー経路で継続、新規作成は不可）に修正。
