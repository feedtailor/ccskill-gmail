## 概要

SKILL.md で `/tmp/` にファイルを書き出す際、絶対パス `/tmp/filename.json` を必ず使用するよう明記する。

## 背景

別プロジェクトで Claude Code が POST 用 JSON を `/tmp/` に Write する際、絶対パスではなく相対パス（`../../../../tmp/filename.json`）で解決するケースが発生した。

パーミッション設定 `Write(/tmp/*)` は絶対パスにのみマッチするため、相対パスで書き出すと許可パターンにマッチせず、ユーザーに確認プロンプトが表示される。

### 発生した事象（2026-04-02）

```
Create file
../../../../tmp/logi-today-confirm.json
Do you want to create logi-today-confirm.json?
```

`Write(/tmp/*)` パーミッションを設定済みにもかかわらず確認が発生した。

## 対応内容

SKILL.md の POST 用 JSON 作成方法セクションに、以下の趣旨の指示を追加する：

```markdown
`/tmp/` へのファイル書き出しは必ず絶対パス（`/tmp/filename.json`）を使用すること。
相対パス（`../../../../tmp/filename.json`）を使うとパーミッション `Write(/tmp/*)` にマッチせず確認プロンプトが発生する。
```
