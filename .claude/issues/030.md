## タスク概要

全インストール先の状態を一覧表示する `commands/status.sh` を新規作成する。

## 背景

レジストリシステム導入により、「どのプロジェクトにインストール済みか」を
一覧表示できるようになる。バージョン比較や outdated 検出も行う。

## 設計

ccskill-spreadsheet の `commands/status.sh` をベースに、Gmail 用に簡略化。

### 出力イメージ

```
ccskill-gmail status (version: abc1234)

  PATH                              VERSION    STATUS
  /Users/oishi/projects/proj-a      abc1234    ✓ up to date
  /Users/oishi/projects/proj-b      def5678    ↑ outdated
  /Users/oishi/projects/proj-c      (not found) ✗ not found

Summary: 1 up to date, 1 outdated, 1 not found
```

### コードスニペット

```bash
#!/bin/bash
set -e

if [ -z "$CCSKILL_GMAIL_DIR" ]; then
    echo "Error: This script should be called via 'ccskill-gmail status'"
    exit 1
fi

source "$CCSKILL_GMAIL_DIR/lib/registry.sh"

# フラグ
JSON_OUTPUT=false
CLEAN_MODE=false

while [ $# -gt 0 ]; do
    case "$1" in
        --json)  JSON_OUTPUT=true; shift ;;
        --clean) CLEAN_MODE=true; shift ;;
        *)       shift ;;
    esac
done

MASTER_VERSION=$(cd "$CCSKILL_GMAIL_DIR" && git rev-parse --short HEAD 2>/dev/null || echo "unknown")

# --clean モード
if [ "$CLEAN_MODE" = true ]; then
    removed=$(registry_clean)
    echo "Removed $removed invalid entries"
    exit 0
fi

registry_init

# JSON出力
if [ "$JSON_OUTPUT" = true ]; then
    jq --arg master_version "$MASTER_VERSION" \
        '. + {master_version: $master_version}' \
        "$_REGISTRY_FILE"
    exit 0
fi

# テーブル表示
echo "ccskill-gmail status (version: $MASTER_VERSION)"
echo ""

PATHS=$(jq -r '.installations | keys[]' "$_REGISTRY_FILE" 2>/dev/null)

if [ -z "$PATHS" ]; then
    echo "  No installations registered."
    echo ""
    echo "  Tip: Use 'ccskill-gmail register <path>' to register existing installations."
    exit 0
fi

UP_TO_DATE=0
OUTDATED=0
NOT_FOUND=0

GREEN='\033[0;32m'
YELLOW='\033[1;33m'
RED='\033[0;31m'
NC='\033[0m'

printf "  %-40s %-12s %s\n" "PATH" "VERSION" "STATUS"

for path in $PATHS; do
    version=$(jq -r --arg p "$path" '.installations[$p].version // "unknown"' "$_REGISTRY_FILE")

    if [ ! -d "$path" ]; then
        printf "  %-40s %-12s ${RED}✗ not found${NC}\n" "$path" "(not found)"
        NOT_FOUND=$((NOT_FOUND + 1))
    elif [ "$version" = "$MASTER_VERSION" ]; then
        printf "  %-40s %-12s ${GREEN}✓ up to date${NC}\n" "$path" "$version"
        UP_TO_DATE=$((UP_TO_DATE + 1))
    else
        printf "  %-40s %-12s ${YELLOW}↑ outdated${NC}\n" "$path" "$version"
        OUTDATED=$((OUTDATED + 1))
    fi
done

echo ""
echo "Summary: $UP_TO_DATE up to date, $OUTDATED outdated, $NOT_FOUND not found"

if [ $OUTDATED -gt 0 ]; then
    echo ""
    echo "Tip: Run 'ccskill-gmail update-all' to update all outdated installations."
fi
```

## オプション

| フラグ | 動作 |
|--------|------|
| `--json` | JSON 形式で出力 |
| `--clean` | 無効なエントリを削除 |
