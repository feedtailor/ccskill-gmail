## 概要

`.claude/skills/ccskill-gmail/SKILL.md` は現在 550 行に肥大化しており、思いつきの順番でセクションが並んでいる。LLM が最初に読むエントリポイントとして「行動規範 (do / don't) と navigation」に絞り、詳細・カタログ・冗長な解説は既存 `reference/` 配下や `examples.md` / `troubleshooting.md` に委譲する。

`reference/` 配下は既に 10 ファイル (約 1,500 行) で API 仕様が整備されており、SKILL.md と重複している箇所が多い。それを統合する。

**目標**: SKILL.md を 200 行以下に圧縮、SKILL.ja.md と同期、リンク切れゼロ。

## 設計方針

1. SKILL.md には「LLM の振る舞いを変える短いルール」と「navigation」だけ残す
2. `<important if="...">` ブロックは必ず本体に残す (skill の inline 注意喚起)
3. 詳細解説・カタログ・列挙は reference/ 配下に切り出す
4. 既存 reference/*.md と重複している箇所はリンクに差し替える
5. SKILL.ja.md は SKILL.md と 1:1 同期分割。reference/*.ja.md は作らない (既存 reference/ の英語のみ運用に合わせる)
