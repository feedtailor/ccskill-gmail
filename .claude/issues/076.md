## 概要

マルチアカウント環境での OAuth 認可失敗時の回復手順を、install プロセスと README の両方で強化する。

## 背景

実機テスト（2026-04-02）で以下のシナリオが発生:

1. `ccskill-gmail install --user info` 実行後、ブラウザで Authorization URL を開くと「このファイルにアクセスできません」表示
2. 指示通りプライベートウィンドウで開いても、既に別の Google アカウントでサインイン済みの場合は同じエラー
3. プライベートウィンドウで accounts.google.com にアクセスし、正しいアカウントで明示的にログインしてから Authorization URL を開くことで解決

現状のトラブルシューティングは「プライベートウィンドウで開け」だけで、プライベートウィンドウ内のアカウント状態まで考慮していない。

## 対応内容

### 1. install.sh の OAuth セクション

Troubleshooting メッセージを以下の手順に拡充:
1. プライベートウィンドウを開く
2. accounts.google.com にアクセスし、対象のアカウントでログイン
3. 同じウィンドウで Authorization URL を貼り付けて開く

### 2. README トラブルシューティング

同様の手順を README.md / README.ja.md のトラブルシューティングセクションに反映。
