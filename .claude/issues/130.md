## 概要

グローバル化・中央アカウントレジストリ化（#121〜#126）により、ccskill-gmail は「プロジェクト単位 install」から「中央アカウント + ユーザースキル」へ設計が変わった。しかし README には**既存ユーザー（中央化前バージョン利用者）向けの移行ガイド**が無く、「自分の環境はどうなるのか」「集約したい場合どうするのか」が分からない。

## 背景

実装上は後方互換が保たれており、既存の `.ccskill-gmail/api` は中央レジストリを見ずに従来動作する（`lib/api:28-39`）。移行は完全に opt-in。ただしこの安心材料が README に書かれていないため、既存ユーザーが更新をためらう / 誤解する余地がある。また #127 で、同一アカウントでも「専用 GAS」と「中央共有 GAS」が二重化しうる罠を踏んでいる。

## 実装内容

- README.md / README.ja.md の `## Update` 直後に移行ガイドセクションを追加:
  1. opt-in しない限り何も変わらない（後方互換）
  2. 中央集約の手順（`account add` → `migrate --dry-run` → `migrate` → 任意 `unbind --purge-legacy`）。再認可不要・設定非削除を明記
  3. 同一アカウントの専用 GAS / 中央共有 GAS 二重化の注意と `api whoami` での endpoint 確認
- Troubleshooting に「変更や操作が反映されない場合 → whoami で endpoint 確認 / account update」を1項目追加
