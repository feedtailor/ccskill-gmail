## 概要

下書き一覧を取得する `list_drafts` アクション（GET）を追加する。
Claude Code 標準 Gmail MCP に存在する機能であり、これを実装することで MCP との機能差を埋める。

## 背景

MCP の `gmail_list_drafts` は下書き一覧をページネーション付きで返す。
ccskill-gmail には `create_draft` / `update_draft` / `delete_draft` はあるが、一覧取得がないため、
既存の下書きを確認する手段がない。

## 実装内容

### 1. gas-template/handlers/draft.js に handleListDrafts を追加

- `GmailApp.getDrafts()` で下書き一覧を取得
- 各下書きから draftId、subject、to、snippet、lastDate を抽出
- `maxResults` パラメータ対応（デフォルト 20）

### 2. gas-template/main.js のルーティングに list_drafts を追加

- GET リクエストで `action=list_drafts` を受け付ける

### 3. スキルドキュメント更新

- .claude/skills/ccskill-gmail/reference/draft.md に list_drafts セクション追加
- SKILL.md の API 一覧に追加
