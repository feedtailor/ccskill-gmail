## 概要

ccskill-gmail リポジトリを public にするための準備。
セキュリティ上の問題解消、ライセンス追加、Claude Code プラグインとしてのマニフェスト作成を行う。

## 背景

ccskill シリーズ第二弾として ccskill-gmail を feedtailor から公開予定。
Claude Code の `/plugin install ccskill-gmail@ccskill` でインストールできる形を目指す。

nanobanana（第一弾）は MIT License で公開済みだが、プラグインシステム未対応。
gmail で先行してプラグイン対応を整え、シリーズ共通のテンプレートとする。

## 実装内容

### 1. セキュリティ（必須）

`.claude/settings.local.json` に GAS エンドポイント URL が含まれている。
公開前に git 追跡から除外する。

- `.gitignore` に `.claude/settings.local.json` を追加
- `git rm --cached .claude/settings.local.json`

### 2. LICENSE 追加（必須）

MIT License（Copyright (c) 2026 feedtailor Inc.）を追加。
nanobanana と統一。

### 3. `.claude-plugin/plugin.json` 作成（必須）

Claude Code プラグインとして認識されるためのマニフェスト。

```json
{
  "name": "ccskill-gmail",
  "version": "1.0.0",
  "description": "Gmail skill for Claude Code - Search, read, draft, and organize emails via GAS Web App",
  "author": {
    "name": "feedtailor Inc.",
    "url": "https://github.com/feedtailor"
  },
  "repository": "https://github.com/feedtailor/ccskill-gmail",
  "license": "MIT",
  "keywords": ["gmail", "email", "ccskill"],
  "skills": "./.claude/skills/ccskill-gmail/"
}
```

※ スキーマの詳細は実機検証時に確認・調整する。

### 4. README 英語版（推奨）

nanobanana は README.md（英語）+ README.ja.md（日本語）の構成。
同じパターンに合わせる。現在の README.md を README.ja.md にリネームし、
英語版 README.md を新規作成。

### 5. Codex CLI 対応ガイド（任意）

Codex CLI は Claude Code プラグインと互換性はないが、
SKILL.md を `.agents/skills/` に配置すれば skill として利用可能。
README にセットアップ手順を記載する。
