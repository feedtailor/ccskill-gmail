## 問題

`handleUpdateDraft` (gas-template/handlers/draft.js) で返信下書きを更新すると、
「削除 → GmailApp.createDraft() で新規作成」のためスレッドとの紐付け
（In-Reply-To / References ヘッダ）が失われる。

## 原因

更新前の実装では、返信下書きであっても `GmailApp.createDraft()` で
新規下書きとして再作成していたため、元のスレッドとの関連が断たれていた。

## 修正内容

### 1. gas-template/handlers/draft.js の handleUpdateDraft を修正

- スレッドのメッセージ数と下書き状態から返信下書きかどうかを判定
- 返信下書きの場合は `createDraftReply` でスレッドの最後の非下書きメッセージに対して再作成
- 新規下書きの場合は従来通り `GmailApp.createDraft()` で再作成
- レスポンスに `threadId` と `isReply` フィールドを追加

### 2. reference/draft.md の update_draft セクションを更新

- レスポンス例に `threadId` と `isReply` を追加
- 返信下書きのスレッド紐付け維持に関する注意事項を更新
