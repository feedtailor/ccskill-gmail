### 変更内容

```javascript
// utils/validation.js - 簡略化
/**
 * 必須パラメータの存在チェック
 * @param {Object} params パラメータオブジェクト
 * @param {string} name パラメータ名
 * @returns {string} パラメータ値
 * @throws {Error} パラメータが存在しない場合
 */
function requireParam(params, name) {
    const value = params[name];
    if (value === undefined || value === null || value === '') {
        throw new Error('Missing required parameter: ' + name);
    }
    return value;
}
```

不要な関数（6関数）を削除してファイルを大幅に縮小。

## 2. snippet フィールドバグ修正

### 問題

`utils/gmail.js` の `formatThread()` 内:

```javascript
// 現在（バグ）: getFirstMessageSubject() は subject を返す
snippet: thread.getFirstMessageSubject(),
```

### 修正

```javascript
// GAS には Thread.getSnippet() がないため、フィールド名を修正
// Option A: フィールド名を subject に変更（実態に合わせる）
subject: thread.getFirstMessageSubject(),

// Option B: 最初のメッセージの body 冒頭を snippet として使う
snippet: thread.getMessages()[0].getPlainBody().substring(0, 200),
```

**推奨: Option A**（パフォーマンス影響なし、API 互換性の観点から）

ただし、`formatThread` の返り値を使っている箇所（search.js）との整合性を確認する必要がある。

### 具体的な修正

```javascript
// utils/gmail.js の formatThread()
function formatThread(thread) {
    var messages = thread.getMessages();
    var lastMessage = messages[messages.length - 1];
    return {
        id: thread.getId(),
        subject: thread.getFirstMessageSubject(),  // ← "snippet" から "subject" に rename
        messageCount: messages.length,
        lastMessage: {
            from: lastMessage.getFrom(),
            date: lastMessage.getDate().toISOString(),
        },
        isUnread: thread.isUnread(),
        labels: thread.getLabels().map(function(label) { return label.getName(); })
    };
}
```

**注意**: この変更は API レスポンスの breaking change になる。
SKILL.md や reference docs で `snippet` を参照している箇所がないか確認が必要。
