## 書き換えパターン

### GET API の書き換え（search.md, read.md）

#### Before
```markdown
### リクエスト
\`\`\`
GET $GMAIL_ENDPOINT?action=search&query=is:unread&maxResults=10
\`\`\`

### curl 例
\`\`\`bash
curl -sL --max-time 60 \
  "$GMAIL_ENDPOINT?action=search&query=$(jq -sRr @uri <<< 'is:unread')&maxResults=10"
\`\`\`
```

#### After
```markdown
### リクエスト
\`\`\`
GET action=search query=<検索クエリ> [maxResults=<数値>]
\`\`\`

### 実行例
\`\`\`bash
ccskill-get "$GMAIL_ENDPOINT" action=search query="is:unread" maxResults=10
\`\`\`
```

### POST API の書き換え（status.md, label.md, draft.md, thread.md）

#### Before
```markdown
### curl 例
\`\`\`bash
curl -sL --max-time 60 \
  -H "Content-Type: application/json" \
  --data '{"action":"create_draft","to":"user@example.com","subject":"件名","body":"本文"}' \
  "$GMAIL_ENDPOINT"
\`\`\`
```

#### After
```markdown
### 実行例
\`\`\`bash
ccskill-post "$GMAIL_ENDPOINT" '{"action":"create_draft","to":"user@example.com","subject":"件名","body":"本文"}'
\`\`\`
```
