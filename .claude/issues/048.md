## 概要

`lib/api.sh` 内の gmail 専用ヘルパー関数 `ccskill-download`, `ccskill-save-html`, `ccskill-save-pdf` を、
ccskill シリーズ共通関数（`ccskill-get`, `ccskill-post`）と区別できる命名にリネームする。

## 背景

`ccskill-` プレフィックスは本来、全 ccskill シリーズ（gmail, spreadsheet, webapp）で共通利用される
API ラッパー関数（`ccskill-get`, `ccskill-post`）のために設計されたもの。
sandbox 制限回避のための共通インターフェースという位置付け。

しかし `ccskill-download`, `ccskill-save-html`, `ccskill-save-pdf` は gmail 専用のローカルユーティリティであり、
GAS API を呼ぶだけでなくローカル側でロジック（base64 デコード、Chrome headless 変換等）を持つ。
同じ `ccskill-` プレフィックスだと「シリーズ共通の関数」と誤解されかねない。

これらの関数は比較的最近（#038-039 前後）で追加されたばかりで、
参照箇所が少ない今のうちにリネームしておくのが望ましい。

## リネーム方針

### 候補

| 現在の名前 | 案A: gmail- | 案B: _gmail_ | 案C: ccskill-gmail- |
|---|---|---|---|
| `ccskill-download` | `gmail-download` | `_gmail_download` | `ccskill-gmail-download` |
| `ccskill-save-html` | `gmail-save-html` | `_gmail_save_html` | `ccskill-gmail-save-html` |
| `ccskill-save-pdf` | `gmail-save-pdf` | `_gmail_save_pdf` | `ccskill-gmail-save-pdf` |

- **案A**: シンプル。gmail 専用であることが明確
- **案B**: `_` プレフィックスでシェル慣習の「内部関数」を明示。アンダースコアで ccskill-get/post との視覚的区別もつく
- **案C**: ccskill ファミリーであることを維持しつつ gmail 専用を明示。やや長い

→ 実装時に最終決定する
