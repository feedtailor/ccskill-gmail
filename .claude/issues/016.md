## タスク概要

下書きを編集・削除する `update_draft` / `delete_draft` API を実装する。

## API 仕様

### update_draft

**アクション**: `update_draft`
**メソッド**: POST

| パラメータ | 必須 | 説明 |
|-----------|------|------|
| draftId | ✓ | 下書き ID |
| to | | 宛先（変更する場合） |
| subject | | 件名（変更する場合） |
| body | | 本文（変更する場合） |
| cc | | CC（変更する場合） |
| bcc | | BCC（変更する場合） |

### delete_draft

**アクション**: `delete_draft`
**メソッド**: POST

| パラメータ | 必須 | 説明 |
|-----------|------|------|
| draftId | ✓ | 削除する下書き ID |


## 実装内容

### 1. handlers/draft.js に追加

```javascript
/**
 * Update an existing draft
 * Note: GmailApp doesn't support direct draft update.
 * We need to delete and recreate the draft.
 */
function handleUpdateDraft(draftId, to, subject, body, cc, bcc) {
  requireParam(draftId, 'draftId');

  // Get existing draft
  const drafts = GmailApp.getDrafts();
  const draft = drafts.find(d => d.getId() === draftId);

  if (!draft) {
    return errorResponse(`Draft not found: ${draftId}`);
  }

  // Get current message content
  const message = draft.getMessage();
  const currentTo = to || message.getTo();
  const currentSubject = subject || message.getSubject();
  const currentBody = body || message.getPlainBody();

  // Build options
  const options = buildEmailOptions({
    cc: cc,
    bcc: bcc
  });

  // Delete old draft and create new one
  draft.deleteDraft();
  const newDraft = GmailApp.createDraft(currentTo, currentSubject, currentBody, options);

  return successResponse({
    draftId: newDraft.getId(),
    oldDraftId: draftId,
    action: 'update_draft',
    message: '下書きを更新しました',
    gmailUrl: 'https://mail.google.com/mail/u/0/#drafts'
  });
}

/**
 * Delete a draft
 */
function handleDeleteDraft(draftId) {
  requireParam(draftId, 'draftId');

  const drafts = GmailApp.getDrafts();
  const draft = drafts.find(d => d.getId() === draftId);

  if (!draft) {
    return errorResponse(`Draft not found: ${draftId}`);
  }

  draft.deleteDraft();

  return successResponse({
    draftId: draftId,
    action: 'delete_draft',
    message: '下書きを削除しました'
  });
}
```

### 2. main.js の doPost に追加

```javascript
case 'update_draft':
  return handleUpdateDraft(
    body.draftId,
    body.to,
    body.subject,
    body.body,
    body.cc,
    body.bcc
  );

case 'delete_draft':
  return handleDeleteDraft(body.draftId);
```

## テスト方法

```bash
source .env

# 1. 下書きを作成
RESULT=$(curl -sL --max-time 60 \
  -H "Content-Type: application/json" \
  --data '{"action":"create_draft","to":"test@example.com","subject":"テスト","body":"本文"}' \
  "$GMAIL_ENDPOINT")
DRAFT_ID=$(echo "$RESULT" | jq -r '.data.draftId')

# 2. 下書きを更新
curl -sL --max-time 60 \
  -H "Content-Type: application/json" \
  --data "{\"action\":\"update_draft\",\"draftId\":\"$DRAFT_ID\",\"subject\":\"件名を変更\"}" \
  "$GMAIL_ENDPOINT"

# 3. 下書きを削除
curl -sL --max-time 60 \
  -H "Content-Type: application/json" \
  --data "{\"action\":\"delete_draft\",\"draftId\":\"$DRAFT_ID\"}" \
  "$GMAIL_ENDPOINT"
```

## 注意事項

- GmailApp は下書きの直接編集をサポートしていない
- update_draft は「削除→再作成」で実装（draftId が変わる）
- 返信下書きの更新は複雑なため、今回はスキップ
