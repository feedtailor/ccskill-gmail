## タスク概要

コマンドディスパッチャスクリプト `ccskill-gmail` を作成する。
`ccskill-gmail <command> [args...]` 形式で全サブコマンドにルーティング。

## 背景

現状は `install.sh` / `update.sh` / `uninstall.sh` が独立スクリプトとして存在。
統一的なコマンド体系にリファクタして UX と保守性を向上させる。

## 作成ファイル

### `ccskill-gmail`（リポジトリルート、実行可能）

```bash
#!/bin/bash
#
# ccskill-gmail - Gmail Skill for Claude Code
#
# Usage: ccskill-gmail <command> [args...]
#

set -e

# Resolve CCSKILL_GMAIL_DIR from this script's location
CCSKILL_GMAIL_DIR="$(cd "$(dirname "$0")" && pwd)"
export CCSKILL_GMAIL_DIR

VERSION=$(cd "$CCSKILL_GMAIL_DIR" && git rev-parse --short HEAD 2>/dev/null || echo "unknown")

show_help() {
    cat << EOF
ccskill-gmail - Gmail Skill for Claude Code

Usage: ccskill-gmail <command> [args...]

Commands:
  install [NAME] [DIR]             Install to a project
  uninstall [DIR]                  Uninstall from a project
  update [--force] [--yes] [DIR]   Update an installation
  update-all                       Update all installations
  apply-config [DIR]               Apply config.js changes to GAS
  register <PATH> [PATH...]        Register existing installations
  status [--json] [--clean]        Show installation status
  help                             Show this help
  version                          Show version

Version: $VERSION
EOF
}

if [ $# -eq 0 ]; then
    show_help
    exit 0
fi

COMMAND="$1"
shift

case "$COMMAND" in
    install)
        exec "$CCSKILL_GMAIL_DIR/commands/install.sh" "$@"
        ;;
    uninstall)
        exec "$CCSKILL_GMAIL_DIR/commands/uninstall.sh" "$@"
        ;;
    update)
        exec "$CCSKILL_GMAIL_DIR/commands/update.sh" "$@"
        ;;
    update-all)
        exec "$CCSKILL_GMAIL_DIR/commands/update-all.sh" "$@"
        ;;
    apply-config)
        exec "$CCSKILL_GMAIL_DIR/commands/apply-config.sh" "$@"
        ;;
    register)
        exec "$CCSKILL_GMAIL_DIR/commands/register.sh" "$@"
        ;;
    status)
        exec "$CCSKILL_GMAIL_DIR/commands/status.sh" "$@"
        ;;
    help|--help|-h)
        show_help
        exit 0
        ;;
    version|--version|-v)
        echo "ccskill-gmail $VERSION"
        exit 0
        ;;
    *)
        echo "Error: Unknown command '$COMMAND'"
        echo ""
        show_help
        exit 1
        ;;
esac
```

## spreadsheet 版との差分

| 項目 | spreadsheet | gmail |
|------|-------------|-------|
| コマンド名 | `ccskill-spreadsheet` | `ccskill-gmail` |
| 環境変数 | `CCSKILL_SPREADSHEET_DIR` | `CCSKILL_GMAIL_DIR` |
| `add` / `remove` コマンド | あり（マルチスプレッドシート） | **なし**（Gmail はマルチ不要） |
| install 引数 | `<URL_OR_ID> [NAME] [DIR]` | `[NAME] [DIR]` |

Gmail は spreadsheet と違ってスプレッドシート ID 指定が不要なので、
`add` / `remove` コマンドは提供しない。
