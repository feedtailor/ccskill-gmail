## 概要

`ccskill-gmail info` コマンドを追加し、現在のプロジェクトに紐付いた ccskill-gmail の詳細情報を表示する。エージェント AI が自分のプロジェクトのアカウント情報やパーミッションを把握するためのコマンド。

## 背景

- `status` は全インストール先の一覧（管理者向け俯瞰ビュー）
- エージェント AI が「自分のプロジェクトのメアドは？使えるアクションは？」を知る手段がない
- `get_profile` API で取れるが、`info` として統合的に見られると便利

## 出力イメージ

```
ccskill-gmail info
================================================

  Account:      oishi@feedtailor.jp
  Directory:    ~/projects/ftgmail
  Version:      81f30fc (up to date)
  Installed:    2026-03-15 10:30:00
  Updated:      2026-04-06 05:43:21

  Permissions:
    Denied:     move_to_trash

  Inbox:        15 unread
  Starred:      3 unread
```

## 実装方針

- `commands/info.sh` を新規作成
- データ取得:
  - `get_profile` API（1回）→ email, inboxUnreadCount, starredUnreadCount
  - レジストリ → version, installedAt, updatedAt
  - `config.js` → permissions.deny
  - マスター VERSION → up-to-date 判定
- API 失敗時（トークン切れ等）はローカル情報のみ表示し、Account/Unread は `(unavailable)`
- `--json` オプション対応

### --json 出力

```json
{
  "account": "oishi@feedtailor.jp",
  "directory": "/Users/oishi/projects/ftgmail",
  "version": "81f30fc",
  "upToDate": true,
  "installedAt": "2026-03-15T10:30:00",
  "updatedAt": "2026-04-06T05:43:21",
  "permissions": { "denied": ["move_to_trash"] },
  "inboxUnread": 15,
  "starredUnread": 3
}
```
