## タスク概要

現在のルートレベル `update.sh` を `commands/update.sh` に移動し、
マスターアーキテクチャ + 自動デプロイ + レガシーマイグレーションに対応する全面リファクタ。

## 背景

現 `update.sh` (228行) の課題:
1. src/ にフルコピーするアーキテクチャ
2. `clasp push` 直接実行（push_gas 未使用）
3. 手動デプロイの注意喚起のみ（自動デプロイなし）
4. レジストリ未対応
5. パーミッション自動設定なし
6. 旧アーキテクチャからの移行パスなし

## 設計方針

```
update フロー:
1. フラグパース: --force, --yes
2. インストール存在チェック
3. メタデータ読み込み（旧パスからの移行含む）
4. バージョン比較 → 更新不要なら終了（--force で強制）
5. 変更ログ表示（git log）
6. アーキテクチャ移行チェック（src/ → master）
7. auth.sh / api.sh の更新
8. スキル定義更新
9. push_gas() で GAS コード push
10. deploy_gas() で自動デプロイ（deployment_id がある場合）
11. setup_permissions() でパーミッション確認
12. registry_upsert() でレジストリ更新
13. メタデータ更新
```

## 主要コードスニペット

### A. フラグパースと初期化

```bash
#!/bin/bash
set -e

if [ -z "$CCSKILL_GMAIL_DIR" ]; then
    echo "Error: This script should be called via 'ccskill-gmail update'"
    exit 1
fi

# フラグパース
FORCE=false
AUTO_YES=false
TARGET_DIR=""

while [ $# -gt 0 ]; do
    case "$1" in
        --force|-f) FORCE=true; shift ;;
        --yes|-y)   AUTO_YES=true; shift ;;
        *)          TARGET_DIR="$1"; shift ;;
    esac
done

TARGET_DIR="${TARGET_DIR:-.}"
TARGET_DIR=$(cd "$TARGET_DIR" && pwd)

# ヘルパーロード
source "$CCSKILL_GMAIL_DIR/lib/push-gas.sh"
source "$CCSKILL_GMAIL_DIR/lib/registry.sh"
source "$CCSKILL_GMAIL_DIR/lib/permissions.sh"
```

### B. アーキテクチャ移行（src/ → master）

```bash
GAS_DIR="$TARGET_DIR/.ccskill-gmail"

# 旧 src/ アーキテクチャの検出
if [ -d "$GAS_DIR/src" ]; then
    echo ""
    echo "━━━ アーキテクチャ移行 ━━━"
    echo "旧レイアウト（src/）から新レイアウト（master）に移行します。"
    echo ""

    # .clasp.json を src/ の外に移動
    if [ -f "$GAS_DIR/src/.clasp.json" ]; then
        # scriptId を保存
        /bin/cp "$GAS_DIR/src/.clasp.json" "$GAS_DIR/.clasp.json"
    elif [ -f "$GAS_DIR/.clasp.json" ]; then
        # rootDir を更新
        if command -v jq &>/dev/null; then
            jq '.rootDir = "."' "$GAS_DIR/.clasp.json" > "$GAS_DIR/.clasp.json.tmp"
            /bin/mv "$GAS_DIR/.clasp.json.tmp" "$GAS_DIR/.clasp.json"
        fi
    fi

    # config.js を保護して移動
    if [ -f "$GAS_DIR/src/config.js" ]; then
        /bin/cp "$GAS_DIR/src/config.js" "$GAS_DIR/config.js"
    fi

    # src/ を削除
    rm -rf "$GAS_DIR/src"

    echo "✓ マスターアーキテクチャに移行完了"
fi
```

### D. GAS push + 自動デプロイ

```bash
# マスターから push
echo "GAS コードを push 中..."
push_gas "$GAS_DIR" "$CCSKILL_GMAIL_DIR"
echo "✓ GAS コード push 完了"

# 自動デプロイ（deployment_id がある場合）
DEPLOYMENT_ID=$(jq -r '.deployment_id // empty' "$METADATA_FILE" 2>/dev/null)
if [ -n "$DEPLOYMENT_ID" ]; then
    echo "自動デプロイ中..."
    deploy_gas "$GAS_DIR" "$DEPLOYMENT_ID" "Update to $NEW_VERSION"
    echo "✓ 自動デプロイ完了（deployment_id: $DEPLOYMENT_ID）"
else
    echo ""
    echo "⚠ deployment_id が未設定のため、手動デプロイが必要です。"
    echo "  GAS エディタでデプロイを更新してください。"
    # GAS エディタ URL を表示
    SCRIPT_ID=$(jq -r '.scriptId' "$GAS_DIR/.clasp.json" 2>/dev/null)
    if [ -n "$SCRIPT_ID" ]; then
        echo "  https://script.google.com/d/${SCRIPT_ID}/edit"
    fi
fi
```

### E. メタデータ更新

```bash
# メタデータ更新（既存フィールドを保持しつつ version, updated_at を更新）
if command -v jq &>/dev/null; then
    local tmp; tmp=$(mktemp)
    jq --arg version "$NEW_VERSION" \
       --arg updated_at "$(date '+%Y-%m-%d %H:%M:%S')" \
       --arg architecture "master" \
       '.version = $version | .updated_at = $updated_at | .architecture = $architecture' \
       "$METADATA_FILE" > "$tmp"
    /bin/mv "$tmp" "$METADATA_FILE"
fi
```
