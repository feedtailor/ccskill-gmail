## タスク概要

スレッドをゴミ箱に移動する `move_to_trash` API を実装する。

## API 仕様

**アクション**: `move_to_trash`
**メソッド**: POST

### パラメータ

| パラメータ | 必須 | 説明 |
|-----------|------|------|
| threadId | ✓ | ゴミ箱に移動するスレッドの ID |

### レスポンス例

```json
{
  "ok": true,
  "data": {
    "threadId": "19bf7f25b96ab637",
    "action": "move_to_trash",
    "message": "スレッドをゴミ箱に移動しました"
  }
}
```

## 実装内容

### 1. handlers/thread.js に追加

```javascript
function handleMoveToTrash(threadId) {
  requireParam(threadId, 'threadId');

  const thread = GmailApp.getThreadById(threadId);
  if (!thread) {
    return errorResponse(`Thread not found: ${threadId}`);
  }

  thread.moveToTrash();

  return successResponse({
    threadId: threadId,
    action: 'move_to_trash',
    message: 'スレッドをゴミ箱に移動しました'
  });
}
```

### 2. main.js の doPost に追加

```javascript
case 'move_to_trash':
  return handleMoveToTrash(body.threadId);
```

## テスト方法

```bash
source .env

# テスト用スレッド ID を取得（注意: 実際に削除される）
THREAD_ID=$(curl -sL --max-time 60 "$GMAIL_ENDPOINT?action=search&query=label:テスト&maxResults=1" | jq -r '.data.threads[0].id')

# ゴミ箱に移動
curl -sL --max-time 60 \
  -H "Content-Type: application/json" \
  --data "{\"action\":\"move_to_trash\",\"threadId\":\"$THREAD_ID\"}" \
  "$GMAIL_ENDPOINT"

# Gmail のゴミ箱で確認
```

## 注意事項

- ゴミ箱のメールは 30 日後に自動削除
- 永久削除 API は安全のため実装しない
- ゴミ箱から復元可能
