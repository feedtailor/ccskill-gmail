## 概要

install / setup スクリプトのユーザー向けメッセージを英語に統一しつつ、日本語での表示にも対応する仕組みを検討する。

## 背景

現状、install スクリプトのメッセージが英語と日本語で混在している（例: 許可パターン設定の案内が日本語）。国際的に使えるツールとしては英語をデフォルトとしつつ、日本語ユーザーへの配慮も必要。

## 検討事項

### 方式案

1. **英語統一（最小工数）**: 全メッセージを英語にする。日本語対応は行わない
2. **環境変数による切り替え**: `LANG` や `LC_MESSAGES` を参照して日本語/英語を切り替え
3. **設定ファイルによる切り替え**: config.js や metadata に言語設定を持つ

### 対象箇所

- `commands/install.sh` の許可パターン設定案内
- `commands/update.sh` の更新確認メッセージ
- `lib/permissions.sh` の確認プロンプト
- GAS 側のエラーメッセージ（hint フィールド）

### 優先度

まずは英語統一（案1）を行い、日本語対応は需要に応じて後から追加するのが現実的。

- [ ] 全ユーザー向けメッセージが選択した方式で統一されている
