## 概要

`ccskill-gmail install --user info@feedtailor.jp` のようにメールアドレスや記号を含む文字列を `--user` に渡すと、Google の OAuth 認証ページで「too many HTTP redirects」が発生し、インストールが完了できない。

## 再現手順

```bash
cd /path/to/project
ccskill-gmail install --user info@feedtailor.jp
```

## 原因

`clasp --user` はプロファイル名（ラベル）を期待しており、値は以下の2箇所で使用される:

1. `~/.clasprc.json` の `tokens` オブジェクトの **JSON キー名**
2. OAuth の **redirect URL パラメータ**

`@` や `/` 等の記号が含まれると、URL エンコードの再帰やパラメータ構造の破壊を引き起こす。

## 対応内容

### 1. バリデーション追加（ホワイトリスト方式）

`--user` の値を **英数字・ハイフン・アンダースコアのみ** に制限する。

```bash
# 例: install.sh の引数パース部分
if [[ ! "$_USER_OVERRIDE" =~ ^[a-zA-Z0-9_-]+$ ]]; then
    echo "Error: --user には英数字・ハイフン・アンダースコアのみ使用できます"
    echo "  例: ccskill-gmail install --user work"
    echo ""
    echo "  事前に clasp --user work login で対象アカウントにログインしてください"
    exit 1
fi
```

対象ファイル:
- `commands/install.sh`（引数パース部分、L62-83 付近）

### 2. ドキュメント補足

README および help 出力で、`--user` にはラベルを指定する旨を明記する。

対象ファイル:
- `README.md`（Technical Details > Multi-account Setup）
- `README.ja.md`（技術詳細 > 複数アカウントで使う場合）
- ヘルプ出力（該当箇所があれば）

### 3. 自動生成パスのサニタイズ

`--user` を指定しない場合、`_CLASP_USER` はディレクトリ名から自動生成される:

```bash
_CLASP_USER="ccskill-gmail-${PROJECT_NAME}"
```

メールアドレスをディレクトリ名に使うケース（例: `gmail-info@feedtailor.jp/`）は実運用で自然に発生する。この場合 `_CLASP_USER` に `@` が混入し、`--user` 明示指定時と同じリダイレクトループが起きる。

対応: 自動生成時に `tr -cd 'a-zA-Z0-9_-'` で記号を除去する。

```bash
_CLASP_USER="ccskill-gmail-$(echo "$PROJECT_NAME" | tr -cd 'a-zA-Z0-9_-')"
```
