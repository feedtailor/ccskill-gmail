## 対応内容

### (1) history の jq フィルタを `--arg` 化（堅牢性）

`lib/history.sh:359-365` で、`HISTORY_FILTER_ACTION` / `HISTORY_FILTER_SINCE` を jq フィルタ文字列へ直接連結している。

```bash
jq_filter="${jq_filter} | select(.action == \"${HISTORY_FILTER_ACTION}\")"
jq_filter="${jq_filter} | select(.timestamp >= \"${HISTORY_FILTER_SINCE}\")"
```

値に `"` を含むとフィルタが壊れる（jq フィルタインジェクション）。これらは CLI 由来の内部入力で exec 不可・自分のログ対象のため実害は低いが、`jq --arg` で値を安全に渡す形へ直す。

- 是正方針: フィルタ文字列にはプレースホルダ変数（例 `$fa` / `$fs`）を使い、`jq --arg fa "$HISTORY_FILTER_ACTION" --arg fs "$HISTORY_FILTER_SINCE"` で値を渡す。`--errors` フィルタ（固定式）は変更不要。

### (2) 不可視文字除去に Unicode タグ文字ブロックを追加（多重防御）

`gas-template/utils/gmail.js:97` の `stripInvisibleChars` 正規表現はゼロ幅・書式制御・BOM を除去するが、プロンプトインジェクションに悪用例のある **Unicode タグ文字（U+E0000–U+E007F）** が対象外。

```javascript
return str.replace(/[​-‏ - ⁠-⁯﻿]/g, '');
```

- 是正方針: タグ文字は補助面（サロゲートペア）なので、`u` フラグを付け `\u{...}` 記法で範囲を追加する。レビュアの素案 `|0-F` は **`u` フラグなしでは誤動作する**ため採用しない。
  ```javascript
  return str.replace(/[​-‏ - ⁠-⁯﻿\u{E0000}-\u{E007F}]/gu, '');
  ```
- 既存範囲は `u` フラグ下でも同一に動作することを確認する。htmlBody は既定で除外（Layer 1）されており、これは Layer 2 の補強。
