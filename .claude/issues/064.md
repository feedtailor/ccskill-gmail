## 概要

`ccskill-gmail update` 実行時のバージョン履歴表示を改善する。

## 背景

現状の表示は `-n 5` で5件に制限されており、フォーマットも `git log --oneline` のまま。
ハッシュやブランチ名が表示されるため、ユーザーにとって情報過多で見づらい。

```
Changes (35 commits):
--------
8e7f6d1 (HEAD -> main) feat: マルチアカウント対応（#053）
1371102 (feature/053-multi-account) feat: マルチアカウント対応（#053）
```

## 実装内容

`commands/update.sh` L148-157 の変更内容表示部分を修正:

1. **5件制限を撤廃** → 全コミットを表示
2. **フォーマット改善** → 日付 + コミットメッセージのみ（ハッシュ・ブランチ名は除外）
   - `--format="  %cd  %s"` + `--date=short` で `YYYY-MM-DD` 形式

### 改善後の表示例

```
Changes (35 commits):
--------
  2026-03-25  feat: マルチアカウント対応（#053）
  2026-03-24  docs: README のセクション構成を再編（Features → Examples → Architecture）
  2026-03-23  docs: README にユースケースセクションを追加
  ...（全件表示）
```
