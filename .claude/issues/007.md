## タスク概要

Gmail の Priority Inbox（重要セクション）に表示されるメールを正確に取得できるよう、レスポンスに `isInPriorityInbox` フィールドを追加する。

## 背景

現在の実装では `isImportant`（重要マーカー）は取得しているが、Gmail UI の「Important」セクションに表示されるメールと一致しない。

調査の結果、GmailApp には `thread.isInPriorityInbox()` メソッドが存在することが判明。これを追加することで、Priority Inbox の表示と一致する結果が得られる可能性がある。

### 現状の問題

```
Gmail UI「Important」セクション: 6件
API `is:important is:unread in:inbox`: 0件 or 不一致
```

### 原因

- `is:important` = Gmail ML が付与する「重要マーカー」（大量のメールに付く）
- Priority Inbox = 表示レイアウト設定で、独自のロジックで「Important and unread」セクションを構成

## 実装内容

### 1. utils/gmail.js の修正

`formatThread()` に `isInPriorityInbox` を追加：

```javascript
function formatThread(thread) {
  // ... existing code ...
  return {
    id: thread.getId(),
    subject: firstMessage.getSubject(),
    // ... existing fields ...
    isUnread: thread.isUnread(),
    isImportant: thread.isImportant(),
    isInPriorityInbox: thread.isInPriorityInbox(),  // 追加
    isInInbox: thread.isInInbox(),
    labels: thread.getLabels().map(function(label) {
      return label.getName();
    })
  };
}
```

### 2. 動作確認

```bash
# Priority Inbox に表示されるメールをフィルタリング
curl -sL --max-time 60 "$GMAIL_ENDPOINT?action=search&query=is:unread&maxResults=50" \
  | jq '[.data.threads[] | select(.isInPriorityInbox == true)] | length'
```
