## 概要

`CLAUDE.md` の「テスト手順」がグローバル化・中央アカウントレジストリ化（#121〜#126）より前の記述のまま取り残されていた。具体的には「`ccskill-gmail update --force --yes .` でデプロイ」と書かれているが、binding 済みプロジェクト（ftgmail 等）では `api` の実行先が**中央アカウント共有 GAS** であり、`update --force .`（レガシー専用 GAS の更新）ではコードが反映されない。

## 発覚経緯

#127 の実機検証（2026-06-16）で、`update --force --yes .` 実行後もバリデーションが効かず、`api whoami` の endpoint と update のデプロイ先 endpoint が不一致であることから判明。正しくは `ccskill-gmail account update`（中央アカウント共有 GAS を更新）だった。

## 実装内容

- `CLAUDE.md`「テスト手順」を中央アカウント前提に書き換え:
  - binding 済みプロジェクトの検証デプロイは `ccskill-gmail account update`
  - レガシー/専用デプロイのみ `update --force --yes .`
  - api 呼び出しをグローバル表記 `ccskill-gmail api ...` に統一
  - `cd` がコールごとにリセットされる点、`whoami` の endpoint 一致確認の注記を追加
