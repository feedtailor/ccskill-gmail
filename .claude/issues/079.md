## 概要

ccskill-gmail の GAS Web App は Claude Code のスキルとしてだけでなく、`.ccskill-gmail/api` を介してシェルスクリプトから直接呼べる Gmail ブリッジ API としても機能する。
この活用方法を SKILL.md と examples.md に明記し、スキルの有用性を高める。

## 背景

実際に ~/projects/gmail-info@feedtailor.jp/ で `extract-spam-data.sh` というスクリプトが作成された。
これは `.ccskill-gmail/api` を使ってスパムメールを検索・取得し、本文からデータを抽出して NDJSON で出力するシェルスクリプト。
Claude Code に「Gmail を操作するスクリプトを作って」と依頼するだけで、スキルが API の使い方を知っているため適切なスクリプトを生成できる。
