## 概要

`ccskill-gmail` の README / ドキュメント上の位置付けを、「Claude/Codex に Gmail を操作させる汎用 Gmail skill」から、「標準 Gmail コネクタではカバーしきれない領域を補完する companion skill」へ変更する。

標準 Gmail コネクタを置き換えるものとして訴求するのではなく、標準コネクタを日常的な検索・閲覧・下書き作成の第一選択とし、`ccskill-gmail` は以下の補完領域を担うものとして再定義する。

## 背景

標準 Gmail / Google Workspace コネクタが利用できる環境では、以下のような基本機能は `ccskill-gmail` 独自の訴求点になりにくい。

- メール検索
- メール閲覧
- 返信下書き作成
- ラベル操作
- 既読/未読
- アーカイブ

一方で、標準コネクタだけでは不便、またはカバーしきれない実務上の領域が残る。

### 1. 機能補完

- 添付ファイルの実体ダウンロード
- メール本文の HTML 保存
- メールの PDF 保存
- ローカルファイル成果物化
- shell script から呼び出せる Gmail bridge API

### 2. 運用補完

- 複数 Gmail / Google Workspace アカウントをプロジェクト単位で bind できる
- `cd` したプロジェクトに応じて使用する Gmail アカウントを固定できる
- 個人・会社・顧客・事業ごとのメールボックス混同を避けられる
- ローカル audit log による操作履歴確認ができる

特に multi-account / project-bound mailbox は、API 機能差ではなく「誤ったアカウントでメールを読んだり下書きを作ったりしない」という実務上の安全性として訴求できる。

## 方針

README の主語を変える。

### Before

> A Claude Code skill for Gmail. Just tell Claude what you want in natural language — search, read, draft replies, organize emails, and more.

### After 案

> ccskill-gmail is a companion skill for Claude/Codex Gmail workflows.
> Use the standard Gmail connector for everyday search, reading, and drafting.
> Use ccskill-gmail when you need project-bound multi-account operation, attachment downloads, email-to-PDF export, or local automation.

日本語版:

> ccskill-gmail は、標準 Gmail コネクタを置き換えるものではありません。
> 通常の検索・閲覧・下書き作成は標準コネクタに任せ、複数アカウントをプロジェクト単位で固定したい場合、添付ファイル取得・メール PDF 化・ローカル自動化が必要な場合に補完的に使う skill です。
