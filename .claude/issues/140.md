## 概要

`setup` を一発完結化（#139）した一方、アンインストールは `skill uninstall` と `account remove <email|label>` を 1 件ずつ手打ちさせる非対称な状態。central 形を一括で撤去する **`ccskill-gmail uninstall --all`** を追加し、`setup`（導入）と対称にする。

## 設計上の制約（コード根拠）

- 既存の `ccskill-gmail uninstall` は**引数なしでカレントディレクトリの per-project install を解除**する（`commands/uninstall.sh:34` で `TARGET_DIR="."`）。よって引数なしを central 用に転用できない。
- そこで **`--all` フラグ**を central フル撤去に割り当てる。`uninstall [DIR]`（レガシー per-project）はそのまま据え置き（retire は #136）。
- 既存資産: スキル解除は `commands/skill.sh` の `cmd_uninstall`、アカウント・GAS 設定・履歴は `~/.ccskill-gmail/`（`accounts.json` / `gas/<clasp_user>/` / `history/`）、CLI symlink は `~/.local/bin/ccskill-gmail`（`commands/setup.sh:65-94`）。

## 変更後の挙動（フル撤去）

`ccskill-gmail uninstall --all` は、ユーザー確認のうえ次をまとめて削除する:

1. ユーザースキル `~/.claude/skills/ccskill-gmail`（symlink / copy どちらも）
2. 中央レジストリ一式 `~/.ccskill-gmail/`（`accounts.json` ＝全アカウント登録、`gas/`、`history/`）
3. CLI symlink `~/.local/bin/ccskill-gmail`（本ツールが張ったものに限る。別実体なら触らない）

**自動削除しないもの**（末尾で手順を案内）:
- GAS プロジェクト本体（Google 側）→ [script.google.com](https://script.google.com) から手動削除
- clasp トークン `~/.clasprc.json`（他用途と共有しうるため）

### 安全策

- 削除対象を一覧表示し、**Y/n 確認（既定 N。破壊的なため）**。`--yes` / `-y` で確認スキップ（CI 用）。
- **`--dry-run`**: 一覧表示のみで削除しない。
- CLI symlink は `readlink` がディスパッチャ実体（`$CCSKILL_GMAIL_DIR/ccskill-gmail`）を指す場合のみ削除。別物なら残し、警告する。
- 対象が存在しない場合はその旨を表示して継続（冪等）。
