## 概要

`create_reply_draft` で、自分が最後に返信したスレッドに対して下書きを作成すると、宛先が自分自身になる問題を修正する。
`skipSelf`（自分の送信メッセージをスキップ）と `replyAll`（CC 自動保持）の2つのパラメータを追加する。

## 背景

現在の `handleCreateReplyDraft` はスレッドの**最後のメッセージ**に対して `createDraftReply()` を呼ぶため、
自分が最後に返信したスレッドでは宛先が自分自身になる。

```
msg[0]: 顧客 → 自分 (CC: A, B)
msg[1]: 自分 → 顧客           ← 最後のメッセージ
msg[2]: create_reply_draft    ← to: 自分 になってしまう
```

暫定回避策として `create_draft` で to/subject を明示指定しているが、スレッド紐付けが失われる。

元提案: b2bios-bizmobile issue#004 実装提案

## 実装内容

### 1. gas-template/handlers/draft.js の handleCreateReplyDraft を修正

- `skipSelf` パラメータ（boolean, デフォルト `true`）を追加
  - `true`: スレッド内メッセージを新しい順に遡り、自分以外が送信したメッセージを返信対象にする
  - 全メッセージが自分の場合は最後のメッセージにフォールバック（現行動作）
- `replyAll` パラメータ（boolean, デフォルト `true`）を追加
  - `true`: `createDraftReplyAll()` を使用（元メッセージの to/cc を自動保持）
  - `false`: `createDraftReply()` を使用（現行動作）
- レスポンスの `to` を `draft.getMessage().getTo()` に変更（実際の下書き宛先を返す）

```javascript
// skipSelf: 自分以外が送信した直近のメッセージを探す
let targetMessage = messages[messages.length - 1]; // フォールバック
if (skipSelf) {
  const myEmail = Session.getActiveUser().getEmail();
  for (let i = messages.length - 1; i >= 0; i--) {
    const from = messages[i].getFrom();
    if (!from.includes(myEmail)) {
      targetMessage = messages[i];
      break;
    }
  }
}

// replyAll に応じて使い分け
const draft = replyAll
  ? targetMessage.createDraftReplyAll(body, options)
  : targetMessage.createDraftReply(body, options);
```

## デフォルト値について

両パラメータともデフォルト `true`。これは既存の動作からの breaking change だが、
現行動作（自分宛てに返信、CC なし）は本来の期待動作ではないため許容する。
