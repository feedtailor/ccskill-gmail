## 確定した事実（コード根拠）

### D（move_to_trash 有効化の dead-end）
- 共有セットアップ済み `.ccskill-gmail/` には `config.js` も `.clasp.json` も生成されない（`install.sh:188-198`）。
- `apply-config` は config.js 不在エラー（`apply-config.sh:44-47`）で必ず exit。
- `move_to_trash` 有効化を案内する 3 つの skill docs（`troubleshooting.md:34-40` / `reference/limitations.md:3` / `reference/thread.md:90`）が dedicated/shared を区別せず「config.js 編集 → apply-config」を**無条件案内** → 共有構成で config.js 不在の dead-end。GAS 側 PERMISSION_DENIED の hint も同様。
- 機能する代替導線（`~/.ccskill-gmail/gas/<clasp_user>/config.js` を編集 → `account update` で push+deploy。`account.sh:360-372` に実在）が**ユーザー向けドキュメントに一切登場せず到達不能**。

### E（確認プロンプト表示整合性）
- `uninstall.sh:133-137` の確認プロンプトが実在有無に関わらず一律「`.claude/skills/`・`.ccskill-gmail/`・`.env` の GMAIL_ENDPOINT を削除」と宣言。bind-only では skill dir も .env エントリも無く、**表示と実態がズレる**（データ損失は無い）。
