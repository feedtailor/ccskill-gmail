## 概要

`main.js` の `doGet` / `doPost` で使用している `switch` 文をルーティングテーブル（オブジェクト）に置き換え、アクション追加時の変更箇所を1箇所に集約する。

## 背景

#066 で `GET_ACTIONS` / `POST_ACTIONS` 定数を導入したが、現状は switch 文と定数配列の2箇所を同期する必要がある。新しいアクション追加時に定数配列の更新を忘れると、WRONG_METHOD エラー検出が機能しない。

## 提案

```javascript
var GET_ROUTES = {
  search: function(e) { return handleSearch(e.parameter.query, parseInt(e.parameter.maxResults) || 20); },
  get_thread: function(e) { return handleGetThread(e.parameter.threadId); },
  // ...
};

var GET_ACTIONS = Object.keys(GET_ROUTES);

function doGet(e) {
  var action = e.parameter.action;
  var handler = GET_ROUTES[action];
  if (handler) return handler(e);
  if (POST_ACTIONS.indexOf(action) !== -1) return wrongMethodError(action, 'POST');
  return unknownActionError(action);
}
```

これにより：
- アクション追加は `GET_ROUTES` or `POST_ROUTES` への1行追加のみ
- `GET_ACTIONS` / `POST_ACTIONS` は `Object.keys()` で自動生成
- switch 文の冗長な列挙が不要に
