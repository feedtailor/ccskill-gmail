## タスク概要

`.claude/skills/ccskill-gmail/SKILL.md` を全面更新し、
生 curl コマンドから `ccskill-get` / `ccskill-post` ラッパーベースに書き換える。

## 背景

現 SKILL.md (270行) は全て生の curl コマンドテンプレートで記述されている。
新しい API ラッパー導入により、以下が変わる:
1. `source .ccskill-gmail/api.sh` で自動初期化
2. `ccskill-get` / `ccskill-post` でリクエスト
3. 認証（Bearer トークン）が自動付与
4. URL エンコードが自動化
5. `-sL --max-time 60` 等のフラグが不要に

### クイックスタートセクション

```markdown
## クイックスタート

### 1. 環境準備

\`\`\`bash
source .ccskill-gmail/api.sh
\`\`\`

これだけで以下が自動的に行われます:
- `.env` から `GMAIL_ENDPOINT` を読み込み
- `auth.sh` から OAuth トークン管理を読み込み
- `ccskill-get` / `ccskill-post` コマンドが使用可能に

### 2. 基本的な使い方

\`\`\`bash
# GET（読み取り）
ccskill-get "$GMAIL_ENDPOINT" action=search query="is:unread"

# POST（書き込み）
ccskill-post "$GMAIL_ENDPOINT" '{"action":"create_draft","to":"user@example.com","subject":"件名","body":"本文"}'
\`\`\`
```

### curl テンプレート書き換え対照表

| API | 旧（生 curl） | 新（ラッパー） |
|-----|---------------|----------------|
| search | `curl -sL --max-time 60 "$GMAIL_ENDPOINT?action=search&query=$(jq -sRr @uri <<< 'is:unread')"` | `ccskill-get "$GMAIL_ENDPOINT" action=search query="is:unread"` |
| get_thread | `curl -sL --max-time 60 "$GMAIL_ENDPOINT?action=get_thread&threadId=xxx"` | `ccskill-get "$GMAIL_ENDPOINT" action=get_thread threadId=xxx` |
| get_message | `curl -sL --max-time 60 "$GMAIL_ENDPOINT?action=get_message&messageId=xxx"` | `ccskill-get "$GMAIL_ENDPOINT" action=get_message messageId=xxx` |
| list_labels | `curl -sL --max-time 60 "$GMAIL_ENDPOINT?action=list_labels"` | `ccskill-get "$GMAIL_ENDPOINT" action=list_labels` |
| get_unread_count | `curl -sL --max-time 60 "$GMAIL_ENDPOINT?action=get_unread_count"` | `ccskill-get "$GMAIL_ENDPOINT" action=get_unread_count` |
| create_draft | `curl -sL --max-time 60 -H 'Content-Type: application/json' --data '{"action":"create_draft",...}' "$GMAIL_ENDPOINT"` | `ccskill-post "$GMAIL_ENDPOINT" '{"action":"create_draft",...}'` |
| 他 POST 系 | 同上パターン | `ccskill-post "$GMAIL_ENDPOINT" '{"action":"...",...}'` |

### レスポンス処理

```markdown
## レスポンス処理

\`\`\`bash
# jq でパース
RESULT=$(ccskill-get "$GMAIL_ENDPOINT" action=search query="is:unread")
echo "$RESULT" | jq '.data.threads[].subject'

# エラーチェック
if echo "$RESULT" | jq -e '.ok == true' > /dev/null 2>&1; then
    echo "成功"
else
    echo "エラー: $(echo "$RESULT" | jq -r '.error')"
fi
\`\`\`
```
