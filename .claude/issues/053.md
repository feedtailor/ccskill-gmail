## 概要

ccskill-gmail を複数 Google アカウントで同時運用できるようにする。clasp の `--user <name>` 機能を活用し、プロジェクトごとにアカウントを切り替える設計。

## 差別化ポイント

既存の Gmail MCP サーバーは基本1トークン=1アカウント。複数アカウントは複数インスタンスの管理が必要。
本スキルはプロジェクトディレクトリ単位で `.ccskill-gmail/` が独立しているため、cd するだけでアカウントが自動切り替わる。

## 設計

### 核心: `CLASP_USER` を `.ccskill-metadata.json` に保存

```json
{
  "installed_from": "/Users/oishi/projects/ccskill-gmail",
  "endpoint": "https://script.google.com/.../exec",
  "clasp_user": "work"
}
```

未設定時は `default` にフォールバック（後方互換）。

### 変更箇所

#### 1. `lib/auth.sh` — `gas_token` のキー動的化

`tokens.default` の全参照箇所を `tokens.${CLASP_USER:-default}` に変更（5-6箇所）。
`CLASP_USER` は api スクリプトが `.ccskill-metadata.json` から読み取って環境変数に設定。

#### 2. `lib/api` — metadata から `CLASP_USER` を読み取り

`_api_init` で `.ccskill-metadata.json` から `clasp_user` を読み、`CLASP_USER` 環境変数に設定。
auth.sh を source する前に設定することで、gas_token が正しいアカウントのトークンを使う。

#### 3. `lib/push-gas.sh` — clasp コマンドに `--user` 渡し

`CLASP_USER` が設定されていれば `clasp --user $CLASP_USER push/deploy` に渡す。

#### 4. `commands/install.sh` — `--user` オプション追加

- `ccskill-gmail install --user work` で指定
- `clasp --user work login` / `clasp --user work create` に渡す
- `.ccskill-metadata.json` に `clasp_user` を保存
- 未指定時は従来通り（`default`、metadata に clasp_user を書かない）

#### 5. `commands/update.sh` — metadata から `CLASP_USER` を読み込み

update 時は `.ccskill-metadata.json` の `clasp_user` を読み取り、push_gas に渡す。

### 後方互換性

- `clasp_user` が metadata にない → `default` にフォールバック → 既存環境は一切影響なし
- シングルアカウントのユーザーは何も変更不要

### ユーザーのオペレーション

```bash
# 1. 仕事用アカウントでログイン
clasp --user work login

# 2. 仕事用プロジェクトをインストール
ccskill-gmail install --user work work-gmail ~/projects/work

# 3. 個人用アカウントでログイン
clasp --user personal login

# 4. 個人用プロジェクトをインストール
ccskill-gmail install --user personal my-gmail ~/projects/personal

# 以降は cd するだけで自動切り替え
cd ~/projects/work
.ccskill-gmail/api get action=search query="is:unread"
# → 仕事用 Gmail

cd ~/projects/personal
.ccskill-gmail/api get action=search query="is:unread"
# → 個人用 Gmail
```
