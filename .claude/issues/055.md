## 概要

エラーレスポンスに `error_code`, `hint`, `retryable` フィールドを追加し、
エージェント AI が「リトライすべきか、設定を直すべきか」を自律的に判断できるようにする。

## エラーコード一覧

| error_code | 意味 | retryable |
|---|---|---|
| NOT_FOUND | リソースが見つからない | false |
| MISSING_PARAM | 必須パラメータ不足 | false |
| INVALID_PARAM | パラメータ値が不正 | false |
| INVALID_JSON | JSON パースエラー | false |
| PERMISSION_DENIED | config.js で拒否 | false |
| UNKNOWN_ACTION | 不明なアクション | false |
| NOT_SUPPORTED | 未対応の操作 | false |
| SIZE_LIMIT | サイズ制限超過 | false |
| INDEX_OUT_OF_RANGE | インデックス範囲外 | false |
| INTERNAL_ERROR | GAS 内部エラー | true |
