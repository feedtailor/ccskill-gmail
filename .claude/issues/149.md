## 概要

#147 では jq のオブジェクトキー `label:` を quote したが、**真因は取りこぼしていた**。
jq 1.5 で `label` は予約語のため、キーだけでなく **変数名 `$label`（`--arg label`）**と
**ドット形式のフィールドアクセス `.label`** も解釈できず、アカウント登録が依然として失敗する。
識別子としての `label` を全て排除して根治する。


## 出典

#147 の fix を pull 済みの利用者マシン（jq-1.5）で `ccskill-gmail account add` を再実行した際の
エラー。quote 済みの行を指したまま同じ構文エラーが出ている。

```
jq: error: syntax error, unexpected label, expecting IDENT or __loc__ (Unix shell quoting issues?) at <top-level>, line 2:
          "label": (if $label == "" then null else $label end),
jq: 1 compile error
```

`expecting IDENT or __loc__` は jq の `$<name>` 文法規則のメッセージ。`$label`（予約語名の変数）が
真の失敗点であることを示す。


## 詳細

### #147 の何が不足していたか

jq 1.5 で `label` は予約語（`label $out | … break $out`）。識別子として使えるあらゆる箇所が壊れる。

| 箇所 | 種別 | #147 後の状態 | jq 1.5 |
|---|---|---|---|
| `"label":` キー | 文字列キー | quote 済み | OK（全版で有効） |
| `--arg label` → `$label` | jq 変数名 | 未対応 | NG（今回のエラー） |
| `.value.label` / `.label` | ドット形式フィールドアクセス | 未対応 | NG の疑い |

`$label` はアカウント**登録**（`accounts_upsert`）で失敗する。`.label` は**実行時**の
`accounts_get`（`api whoami` 等が毎回呼ぶ）や `account list` でも失敗しうるため、
登録が通っても api が動かない恐れがあった。

### 該当箇所

- `lib/accounts.sh`: `--arg label`(144) / `$label`(153) / `select(.value.label ...)`(182) /
  `any(...; .label == $l)`(315)
- `commands/account.sh`: `(.value.label // "-")`(227) / `jq -r '.label // empty'`(384)


## 方針

識別子から予約語 `label` を完全に排除する。角括弧・別名化はどの jq 版でも有効な書き方。

- 変数: `--arg label` → `--arg lbl`、`$label` → `$lbl`
- フィールド: `.value.label` → `.value["label"]`、`.label` → `.["label"]`
- キー `"label":` は #147 の quote を維持
