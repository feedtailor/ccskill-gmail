## タスク概要

メッセージまたはスレッドを既読/未読にする `mark_read` / `mark_unread` API を実装する。

## API 仕様

### mark_read

**アクション**: `mark_read`
**メソッド**: POST

| パラメータ | 必須 | 説明 |
|-----------|------|------|
| threadId | ※ | スレッド ID（threadId または messageId のいずれか必須） |
| messageId | ※ | メッセージ ID |

### mark_unread

**アクション**: `mark_unread`
**メソッド**: POST

| パラメータ | 必須 | 説明 |
|-----------|------|------|
| threadId | ※ | スレッド ID（threadId または messageId のいずれか必須） |
| messageId | ※ | メッセージ ID |

### レスポンス例

```json
{
  "ok": true,
  "data": {
    "threadId": "19bf7f25b96ab637",
    "action": "mark_read",
    "message": "スレッドを既読にしました"
  }
}
```

## 実装内容

### 1. handlers/read.js に追加（または新規 handlers/status.js）

```javascript
function handleMarkRead(threadId, messageId) {
  if (!threadId && !messageId) {
    return errorResponse('Either threadId or messageId is required');
  }

  if (threadId) {
    const thread = GmailApp.getThreadById(threadId);
    if (!thread) {
      return errorResponse(`Thread not found: ${threadId}`);
    }
    thread.markRead();
    return successResponse({
      threadId: threadId,
      action: 'mark_read',
      message: 'スレッドを既読にしました'
    });
  } else {
    const message = GmailApp.getMessageById(messageId);
    if (!message) {
      return errorResponse(`Message not found: ${messageId}`);
    }
    message.markRead();
    return successResponse({
      messageId: messageId,
      action: 'mark_read',
      message: 'メッセージを既読にしました'
    });
  }
}

function handleMarkUnread(threadId, messageId) {
  if (!threadId && !messageId) {
    return errorResponse('Either threadId or messageId is required');
  }

  if (threadId) {
    const thread = GmailApp.getThreadById(threadId);
    if (!thread) {
      return errorResponse(`Thread not found: ${threadId}`);
    }
    thread.markUnread();
    return successResponse({
      threadId: threadId,
      action: 'mark_unread',
      message: 'スレッドを未読にしました'
    });
  } else {
    const message = GmailApp.getMessageById(messageId);
    if (!message) {
      return errorResponse(`Message not found: ${messageId}`);
    }
    message.markUnread();
    return successResponse({
      messageId: messageId,
      action: 'mark_unread',
      message: 'メッセージを未読にしました'
    });
  }
}
```
