## 概要

private repository の状態で他のユーザーに配布できるよう、zip 圧縮ファイルでの提供に対応する。

## 背景

現状は `git clone` 前提の配布方式のみ。private repo を共有するには
コラボレーター招待が必要だが、zip 配布なら手軽に試してもらえる。

## 対応が必要な箇所

### 1. VERSION ファイルの同梱
- リリース用 zip 作成時に `git rev-parse --short HEAD` の結果を `VERSION` ファイルに書き出す
- `install.sh` / `update.sh` が `VERSION` ファイルを優先的に参照するよう変更

### 2. update コマンドの非 git 対応
- `.git` がない場合、`git pull` / `git log` / `git rev-parse` をスキップ
- 「新しい zip を展開して上書き → `ccskill-gmail update` で各プロジェクトに反映」フローを案内

### 3. zip 作成スクリプト
- `ccskill-gmail release` または Makefile で zip を生成
- `.git`, `.claude/issues`, `review_*.md` 等の開発用ファイルを除外
- VERSION ファイルを自動生成して同梱

### 4. README にセットアップ手順を追記
- zip 展開 → PATH 追加 → `ccskill-gmail install` の手順
- git clone 方式との違い（update の手順が異なる）を明記
