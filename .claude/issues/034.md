### 書き換えパターン例

#### Before（現在）
```bash
# 未読メール確認
source .env
RESULT=$(curl -sL --max-time 60 \
  "$GMAIL_ENDPOINT?action=search&query=$(jq -sRr @uri <<< 'is:unread')")
echo "$RESULT" | jq '.data.threads[] | {subject, from: .lastMessage.from}'
```

```bash
# 未読メール確認
source .ccskill-gmail/api.sh
RESULT=$(ccskill-get "$GMAIL_ENDPOINT" action=search query="is:unread")
echo "$RESULT" | jq '.data.threads[] | {subject, from: .lastMessage.from}'
```

### 追加するセクション

```markdown
## 認証エラー (401 / アクセス拒否)

### 症状
- レスポンスが HTML（Google ログインページ）
- `{"ok":false,"error":"Authorization required"}` のようなエラー

### 原因と対処

1. **clasp にログインしていない**
   \`\`\`bash
   clasp login
   \`\`\`

2. **トークンが期限切れ（自動リフレッシュ失敗）**
   \`\`\`bash
   # ~/.clasprc.json を確認
   jq '.tokens.default.expiry_date' ~/.clasprc.json
   # 再ログイン
   clasp login
   \`\`\`

3. **デプロイが "Anyone" のまま**
   - GAS エディタでデプロイ設定を確認
   - 「自分のみ」(MYSELF) に変更して再デプロイ

4. **api.sh を source していない**
   \`\`\`bash
   # ✗ 直接 curl（Bearer トークンなし）
   curl -sL "$GMAIL_ENDPOINT?action=list_labels"

   # ✓ api.sh 経由（自動認証）
   source .ccskill-gmail/api.sh
   ccskill-get "$GMAIL_ENDPOINT" action=list_labels
   \`\`\`
```

### 更新するセクション

```markdown
## タイムアウトエラー

（変更なし - ccskill-get/post は内部で --max-time 60 を設定済み）

## Unknown action エラー

### 原因
GET/POST の使い分けが間違っている。

### 対処
- 読み取り系: `ccskill-get` を使用
- 書き込み系: `ccskill-post` を使用

## 日本語検索の問題

### 以前の問題
日本語を URL エンコードする必要があった。

### 現在の対処
ccskill-get は値を自動的に URL エンコードするため、日本語をそのまま渡せます:
\`\`\`bash
ccskill-get "$GMAIL_ENDPOINT" action=search query="from:田中太郎"
\`\`\`
```
