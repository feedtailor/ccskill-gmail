## 概要

ccskill シリーズを一元配布するための Claude Code プラグインマーケットプレイスを
`feedtailor/ccskill` リポジトリとして構築する。

## 保留の経緯（2026-04-08）

Claude Code のプラグイン仕様を調査した結果、現時点では保留とする。

### 判断理由

`/plugin install` はファイル配置（スキル定義、hooks 等）のみを行う仕組みであり、
ccskill-gmail が必要とする以下のセットアップ工程をカバーできない:

- clasp のインストール・ログイン
- GAS プロジェクトの作成・デプロイ
- OAuth 認証（Gmail スコープの許可）
- `.ccskill-gmail/` ディレクトリの生成（api スクリプト、auth.sh 等）

つまり `/plugin install` 後に結局 `ccskill-gmail setup` + `ccskill-gmail install` が
必要となり、マーケットプレイス経由のインストール体験が中途半端になる。

### 再開の条件

Claude Code プラグインに `postInstall` hook 等、インストール後のセットアップスクリプト
実行をサポートする仕組みが追加された場合に再検討する。

### 検討した代替案

| 案 | 判断 | 理由 |
|----|------|------|
| マーケットプレイスを「発見の場」として使い、hooks で案内表示 | 不採用 | インストールしたのに動かない体験はユーザーを混乱させる |
| 現行の `git clone` + `ccskill-gmail install` を正規導線に維持 | 採用 | セットアップ工程を含む完全な導線を提供できる |

### 現状の準備状況

以下は完了済みのため、再開時にすぐ着手できる:

- ccskill-gmail: `.claude-plugin/plugin.json` 作成済み
- ccskill-gmail: `skills` パスのカスタム指定済み（`./.claude/skills/ccskill-gmail/`）
