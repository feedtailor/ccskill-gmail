## 変更範囲（差分ベース）

### 1. 冒頭の初期化

```bash
#!/bin/bash
set -e

# ディスパッチャ経由チェック
if [ -z "$CCSKILL_GMAIL_DIR" ]; then
    echo "Error: This script should be called via 'ccskill-gmail uninstall'"
    exit 1
fi

TARGET_DIR="${1:-.}"
TARGET_DIR=$(cd "$TARGET_DIR" && pwd)

# レジストリヘルパーロード
source "$CCSKILL_GMAIL_DIR/lib/registry.sh"
```

### 2. 削除処理にレジストリ連携追加

```bash
# 既存の削除処理...
# .claude/skills/ccskill-gmail/ 削除
# .ccskill-gmail/ 削除
# .env から GMAIL_ENDPOINT 削除

# NEW: レジストリからエントリ削除
registry_remove "$TARGET_DIR"
echo "✓ レジストリからエントリを削除"
```

### 3. マスターアーキテクチャ対応

```bash
# GAS ディレクトリの検出（両方のアーキテクチャに対応）
GAS_DIR="$TARGET_DIR/.ccskill-gmail"

if [ ! -d "$GAS_DIR" ]; then
    echo "Error: .ccskill-gmail/ が見つかりません。インストールされていない可能性があります。"
    exit 1
fi

# Script ID の取得（.clasp.json の場所がアーキテクチャにより異なる）
if [ -f "$GAS_DIR/.clasp.json" ]; then
    SCRIPT_ID=$(jq -r '.scriptId // empty' "$GAS_DIR/.clasp.json" 2>/dev/null)
elif [ -f "$GAS_DIR/src/.clasp.json" ]; then
    SCRIPT_ID=$(jq -r '.scriptId // empty' "$GAS_DIR/src/.clasp.json" 2>/dev/null)
fi
```
