## 概要

recipe-creator が Claude Code のローカル会話履歴 (`~/.claude/projects/-*/session-*.jsonl`) を opt-in で参照し、ユーザーが繰り返し投げているプロンプトパターンからレシピ候補を抽出する。あわせて時系列規則性検出と能動提案を追加する。

## 背景

#102 の構想に基づく Phase 4。#105 (MVP) の上に乗せる発展機能。

audit.jsonl だけでは「ユーザーが AI にどのような自然言語プロンプトを投げているか」が分からない。会話履歴を参照することで、「毎週同じ依頼を出している」「同じ質問を繰り返している」といった高次のパターンが抽出できる。ただし会話履歴には機密情報が含まれうるため、opt-in 必須とする。

## 実装内容

### 1. 会話履歴参照 (opt-in)

- `config.js` に `recipeCreator.useConversationHistory: false` を追加 (デフォルト無効)
- 有効化時のみ `~/.claude/projects/-*/session-*.jsonl` を走査
- 初回有効化時に privacy notice を表示し明示的な同意を要求
- 抽出対象: ユーザー発話のうち ccskill-gmail 関連と思われるもの (キーワード検出でフィルタ)
- 走査範囲は過去 N 日分に制限 (デフォルト 30 日など)

### 2. 時系列規則性検出

audit.jsonl から時系列パターンを検出:
- 毎週月曜朝、毎月 1 日、毎日夕方、等の規則的タイミング
- 検出時は recipe 生成時に「スケジュール実行を提案しますか？」と尋ね、cron/loop 設定の雛形を提示

### 3. 能動提案 (opt-in)

ccskill-gmail の通常利用中にも「これ過去 N 回やってますね、レシピ化しますか？」と AI から提案:

- 頻度が閾値を超えたらフラグが立つ
- `config.js` の `recipeCreator.proactiveSuggestion: false` (デフォルト無効)
- 通知頻度の制限 (1 セッションに 1 回等)
- ユーザー設定で完全無効化可能

### 4. 提案の精度向上

MVP (#105) の頻度ベース検出に加え:
- action シーケンスのパターンマッチング強化
- 会話コンテキストからレシピ名・目的の推測
- 既存レシピとの重複回避 (亜種ならレシピ改善提案)

## プライバシー

会話履歴には業務上の機密情報が含まれる可能性があるため、厳格なルールを課す:

- **opt-in 必須**: 明示的に有効化しない限り一切読まない
- **初回有効化時の privacy notice**: どのファイルを読むか、何を抽出するかを明示
- **原文を保存しない**: 内部的にパターン抽出した後、原文や抜粋は破棄
- **本文を提案に含めない**: audit.jsonl の #050 設計原則を踏襲 (action 名・頻度のみ)
- **走査範囲の制限**: 過去 N 日に限定、設定で上限変更可能
- **無効化時の完全停止**: opt-out 後は一切参照しない
