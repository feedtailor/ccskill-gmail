## 概要

Google が Workspace at Next 2026 で **Workspace MCP Server（プレビュー）** を発表した。Gmail 系ツールが公式 MCP として Google 運用で提供されるため、ccskill-gmail の比較対象は従来の「Claude.ai 標準 Gmail Connector」だけでなく、この公式 MCP も含めて整理し直す必要がある。

#109 で「標準コネクタ補完 skill」へ pivot 済みだが、その時点では公式 MCP は射程に入っていなかった。README / SKILL の比較表と訴求文を、公式 MCP の登場を前提に更新する。

## 公式 Workspace MCP（Gmail）の現状

- 提供形態: **Google 運用、プレビュー**
- ツール（10 個）:
  - `search_threads` / `get_thread`
  - `create_draft` / `list_drafts`
  - `list_labels` / `create_label`
  - `label_message` / `label_thread` / `unlabel_message` / `unlabel_thread`
- OAuth スコープ: `gmail.readonly` + `gmail.compose` のみ
  - **`gmail.modify` は無い** → archive / trash / 既読・未読切替 / star は不可
  - **送信機能は無い**（ccskill-gmail と同方針）
- 認可: OAuth 2.0、ユーザー権限とガバナンスを継承
- 追って **Workspace CLI** も提供予定

## ccskill-gmail との重なり / 差分の整理

### 公式 MCP がカバーする領域（ccskill-gmail の独自価値が薄れる部分）

- メール検索・スレッド取得
- 下書き作成・下書き一覧
- ラベル管理一式（**標準 Gmail Connector には無かったので、ここは新たに被った**）

### ccskill-gmail にしか無い領域（再ポジショニングの軸にすべき部分）

1. **`gmail.modify` を要する操作群**
   - archive / move_to_trash / 既読・未読切替 / star / important
   - 公式 MCP はスコープ的に踏み込んでいないので、当面は ccskill-gmail の独壇場
2. **添付ファイルのダウンロード**（公式 MCP に明記なし）
3. **本文の PDF 化**（HTML / プレーンテキスト両対応）
4. **マルチアカウント / プロジェクトディレクトリ単位の bind**
5. **ローカル監査ログ**
6. **プロンプトインジェクション対策**（不可視文字除去・境界マーカー）
7. **任意の Gmail スクリプト構築土台**（`.ccskill-gmail/api`）
