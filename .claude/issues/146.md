## 概要

`v1.0.0` リリース作業中、`ccskill-gmail release` が生成する配布 zip に以下の混入を確認した。

1. `.claude/skills/nano-banana-pro` — ccskill-gmail と無関係なローカルスキルへの **symlink** が git 追跡されており、リンク先 `/Users/oishi/projects/ccskill-nanobanana/...`（個人環境の絶対パス）が公開リポジトリにも入っていた。zip 生成時に symlink をたどってスキル中身一式が同梱されていた。
2. `.DS_Store` / `log/2026-06-18.md` — git 管理外のローカル産物。`release.sh` がワークツリー全体を zip 化するため混入。
3. `VERSION` ファイルの中身が短縮ハッシュ（`e5a3e72`）。タグ付き時はタグ（`v1.0.0`）が自然。

## 対応内容

### (1) symlink を追跡から除去（公開リポジトリの是正）

- `git rm --cached .claude/skills/nano-banana-pro` で追跡解除。
- `.gitignore` に「製品スキルのみ追跡、その他は除外」を追加し再混入を防止。
  ```
  /.claude/skills/*
  !/.claude/skills/ccskill-gmail/
  ```

### (2) release.sh を git 追跡ファイルベースに変更

- git リポジトリ時は `git ls-files`（追跡ファイルのみ）を同梱。これにより `.DS_Store`・`log/`・追跡対象外 symlink が構造的に混入しない。
- `.claude/issues/`（開発用・145件）は従来どおり zip から除外（git pathspec `':!.claude/issues/'`）。
- 非 git（zip 再配布物からの再生成）はワークツリー zip にフォールバックしつつ除外パターンを強化。
- VERSION とzip名を `git describe --tags --always` 由来に統一（タグ付き時 `v1.0.0`）。
