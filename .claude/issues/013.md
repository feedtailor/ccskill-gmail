## タスク概要

スレッドをアーカイブする `archive` API を実装する。

## API 仕様

**アクション**: `archive`
**メソッド**: POST

### パラメータ

| パラメータ | 必須 | 説明 |
|-----------|------|------|
| threadId | ✓ | アーカイブするスレッドの ID |

### レスポンス例

```json
{
  "ok": true,
  "data": {
    "threadId": "19bf7f25b96ab637",
    "action": "archive",
    "message": "スレッドをアーカイブしました"
  }
}
```

## 実装内容

### 1. handlers/thread.js を新規作成

```javascript
/**
 * Gmail Skill - Thread Handlers
 *
 * Thread operations: archive, move to trash.
 */

function handleArchive(threadId) {
  requireParam(threadId, 'threadId');

  const thread = GmailApp.getThreadById(threadId);
  if (!thread) {
    return errorResponse(`Thread not found: ${threadId}`);
  }

  thread.moveToArchive();

  return successResponse({
    threadId: threadId,
    action: 'archive',
    message: 'スレッドをアーカイブしました'
  });
}
```

### 2. main.js の doPost に追加

```javascript
case 'archive':
  return handleArchive(body.threadId);
```

## テスト方法

```bash
source .env

# スレッド ID を取得
THREAD_ID=$(curl -sL --max-time 60 "$GMAIL_ENDPOINT?action=search&query=in:inbox&maxResults=1" | jq -r '.data.threads[0].id')

# アーカイブ
curl -sL --max-time 60 \
  -H "Content-Type: application/json" \
  --data "{\"action\":\"archive\",\"threadId\":\"$THREAD_ID\"}" \
  "$GMAIL_ENDPOINT"

# Gmail で確認（受信トレイから消えている）
```

## 注意事項

- アーカイブは受信トレイからの削除のみ（メール自体は残る）
- 「すべてのメール」で確認可能
- ラベルは維持される
