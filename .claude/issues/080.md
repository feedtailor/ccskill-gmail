## 概要

`ccskill-gmail status` の出力に、各インストール先が紐付いている Gmail アカウント（メールアドレス）を表示する。

## 現状

```
  PATH                                     VERSION      STATUS
  ~/projects/ftgmail                       81f30fc      up to date
  ~/projects/gmail-info@feedtailor.jp      f612a82      outdated
```

パスからアカウントを推測するしかなく、複数アカウントを使っている場合に不便。

## ゴール

```
  PATH                                     ACCOUNT                  VERSION      STATUS
  ~/projects/ftgmail                       oishi@feedtailor.jp      81f30fc      up to date
  ~/projects/gmail-info@feedtailor.jp      info@feedtailor.jp       f612a82      outdated
```

## 実装方針

- `install.sh` の処理中に `get_profile` API を呼び、返却された `email` を `.registry.json` に保存する
- `status.sh` は通常時はレジストリの `email` をそのまま表示（API コールなし、軽量）
- email 未取得の場合は `(unknown)` と表示
- `status --refresh` オプションで各インストール先の `get_profile` を呼んで email を更新・保存する
- `--json` 出力にも `email` フィールドを含める
